# Arcanum — обучающее приложение по таро

@AGENTS.md

## Контекст проекта

Приложение для изучения таро (курс как в Duolingo + карта дня + справочник 78 карт + расклады).
Делают Артём (новичок в разработке — объясняй просто, по-русски) и его жена (эксперт-таролог,
главный редактор контента). Полный план: `docs/master-plan.md` — **прочитай его перед крупными задачами**.

## Жёсткие правила

1. **SDK НЕ обновлять.** Проект на Expo SDK 54, потому что Expo Go в App Store поддерживает только SDK 54
   (политика Expo с мая 2026). Не запускать `expo upgrade`, не менять мажорные версии пакетов.
2. **Язык общения — русский.** Комментарии в коде — тоже русские.
3. После каждой правки код должен проходить `npx tsc --noEmit` без ошибок.
4. Если меняешь `package.json` или `app.json` — явно скажи Артёму: «нужен npm install и перезапуск
   `npx expo start --tunnel`». Обычные правки кода подхватываются Fast Refresh автоматически.
5. **Бэкенда нет и в v1 не будет** — всё офлайн: контент в JSON-бандле, прогресс в AsyncStorage/SQLite.
6. Тексты значений карт **не выдумывать**: их пишет редактор (жена). В коде показывать блоки со
   статусом `todo` как «Текст готовится» (см. `content/cards.json`, статусы: todo → draft → reviewed → final).
7. Git: коммить осмысленными шагами с русскими сообщениями.

## Дизайн — какой файл для чего (ЧИТАТЬ ПЕРЕД ЛЮБОЙ РАБОТОЙ НАД UI)

Направление — **«Небесное золото»**: глубокая ночная синева + шампанское золото, БЕЗ фиолетового.

| Файл | Что это | Когда обращаться |
|---|---|---|
| `docs/design-system.md` | **Все численные значения**: цвета, типографика, отступы, радиусы, тени, спецификации компонентов, состояния, тон текстов | Всегда при создании/правке любого экрана или компонента. При конфликте с кодом — прав этот файл |
| `docs/design-reference.html` | **Визуальный эталон**: интерактивный макет всех экранов (композиция, анимации в CSS с точными параметрами). Читай его код: значения в CSS — источник правды для композиции | Когда делаешь конкретный экран — найди его в макете и сверь композицию; параметры анимаций бери из CSS |
| `docs/motion-spec.md` | **14 анимаций** по приоритетам с параметрами (длительности, кривые, пакеты) + анти-чеклист | Любая работа с анимациями; делать по одному пункту за коммит |
| `src/theme/theme.ts` | **Токены в коде** (обе темы) | Цвета ТОЛЬКО отсюда, хардкод цветов запрещён |
| `docs/master-plan.md` | План проекта: этапы, фичи удержания, монетизация | Перед крупными задачами и при вопросах «зачем/что дальше» |

Порядок работы над UI-задачей: design-system.md (значения) → design-reference.html (композиция экрана)
→ motion-spec.md (если есть движение) → код с токенами из theme.ts → `npx tsc --noEmit`.

## Структура

- `app/` — экраны (expo-router): (tabs)/ = Сегодня, Курс, Карты, Расклады, Профиль; card/[id] — страница карты
- `src/theme/` — токены и useTheme; `src/store/useApp.ts` — Zustand-состояние (тема, язык, серия, история)
- `src/lib/content.ts` — доступ к контенту; `src/lib/cardImages.ts` — АВТОГЕНЕРИРУЕТСЯ (`scripts/gen_card_images.py`), не править руками
- `src/lib/srs.ts` — алгоритм интервальных повторений SM-2 (для флеш-карт, этап 4)
- `content/*.json` — 78 карт / 8 раскладов / курс 6 модулей (двуязычные ru/en)
- `assets/cards/` — 78 изображений Райдер–Уэйт (public domain)

## Статус (на 8 августа 2026)

Сделано: каркас 5 табов, карта дня с 3D-переворотом и вибрацией, серия (streak) с персистом,
справочник 78 карт (expo-image с кэшем), страница карты, курс и расклады списками, профиль
(переключение темы/языка), i18n ru/en. Проверено на iPhone через Expo Go.

## Ближайшие задачи (этапы 1–2 плана)

1. Кнопка «сбросить карту дня» в профиле (только для разработки).
2. Перенос шлифованного дизайна из docs/design-reference.html: кольца вокруг карты, шрифт с кириллицей
   (Cormorant Garamond через expo-font), градиентный фон.
3. Дневник: заметка к карте дня + вечерняя рефлексия «сбылось?» + история в профиле.
4. Экран курса → «путь» как в Duolingo (см. эталон).
5. Онбординг: имя + дата рождения → аркан рождения (вау-момент первого запуска).

Полный план этапов, фичи удержания (16 пунктов), монетизация и метрики — в `docs/master-plan.md`.
