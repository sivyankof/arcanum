# Чек-лист автопроверки UI (шаги 6а/6б процесса)

Как запускать: `npx expo start --web` → приложение на http://localhost:8081. Макет: docs/design-reference.html
(открыть file://). Скриншоты: viewport 390×844, обе темы, складывать в docs/screenshots/<NN-spec>/
(например 01/today-dark.png, 01/today-light.png). Скриншоты коммитятся — это визуальная история проекта.

## 6а. Визуальная сверка (скриншот против макета)

Для каждого изменённого экрана проверь по пунктам:

- [ ] **Композиция**: те же блоки в том же порядке, ничего не потеряно и не добавлено от себя
- [ ] **Фон**: градиент сверху-вниз как в макете; в тёмной теме видны звёзды, в светлой — нет
- [ ] **Типографика**: заголовки — Cormorant (засечки!), размеры по design-system.md §2; overline-подписи
      в верхнем регистре с letterSpacing; НИГДЕ нет системного шрифта там, где должен быть serif
- [ ] **Цвета**: золото = accent из темы (не жёлтый, не оранжевый); текст не чисто-белый (#fff запрещён);
      сравни пипеткой 2–3 ключевых цвета скриншота с макетом (допуск ±5%)
- [ ] **Отступы**: поля экрана 24; между панелями 12; ничего не прилипло к краям и к таб-бару
- [ ] **Карты таро**: у всех изображений золочёная рамка frame; пропорция 0.58 не искажена
- [ ] **Обе темы**: светлая проверена отдельно — контраст достаточный, ни один элемент не «исчез»
- [ ] **Анимации**: кольца вращаются плавно; каскад появления есть; ничего не мигает и не дёргается

## 6б. Прокликивание интерактива

Пройди КАЖДЫЙ элемент изменённых экранов (и смежных, если менялась навигация):

- [ ] Все 5 табов: переключаются, активный подсвечен золотом, экран открывается без белых вспышек
- [ ] «Сегодня»: тап по рубашке → переворот, появляется название + значение + CTA; повторный тап
      ничего не ломает; CTA ведёт на страницу карты
- [ ] «Карты»: каждый фильтр (Все/Старшие/4 масти) даёт правильное число карт (78/22/14/14/14/14),
      «Изучено» — число изученных; панель «Изучено N из M» следует за чипом; неизученные приглушены;
      тап по 2–3 картам из разных мастей открывает их страницы; назад работает
- [ ] Страница карты: все блоки на месте, «Текст готовится» только у статуса todo (после заполнения
      базы таких быть не должно — если есть, это баг данных)
- [ ] «Курс»: список модулей, замки на платных; «Расклады»: 8 штук, PREMIUM-бейджи
- [ ] Профиль: переключение темы меняет ВСЁ приложение мгновенно; переключение языка RU↔EN меняет
      табы, заголовки и тексты карт; настройки переживают перезагрузку страницы
- [ ] Консоль браузера: ноль красных ошибок; warnings перечислить в отчёте
- [ ] Отчёт в конце: таблица «элемент → ожидание → факт → ✓/✗», расхождения с макетом с причинами

## Опционально: нативная автопроверка (Android-эмулятор)

Если Артём установит Android Studio (+эмулятор Pixel), добавляется уровень: открыть проект в эмуляторе
(клавиша `a` в expo start), скриншоты через `adb exec-out screencap -p > shot.png`, тапы через
`adb shell input tap X Y`. Даёт настоящие тени/шрифты/анимации. Предложить установку при задаче 03,
не раньше — сначала выстроить веб-цикл.
