## 0. Онбординг ✅ (09, реализовано 13.08)

Показывается один раз при первом запуске (`profile.onboarded` в AsyncStorage). Механика показа —
`Stack.Protected` в корневом layout: при `onboarded: false` онбординг остаётся ЕДИНСТВЕННЫМ доступным
маршрутом, и роутер садится на него сам. Сплэш держится до загрузки шрифтов И до гидрации persist,
поэтому «Сегодня» не мелькает ни у новичка, ни у вернувшегося.

**Шаг 1 — приветствие.** Эмблема-компас (вращение 40s), «Arcanum», подзаголовок «Научитесь читать таро —
по 5 минут в день». CTA «НАЧАТЬ ПУТЬ». Точки-прогресс (1/3).
**Шаг 2 — о вас.** Поля: имя (текст, необязательное — если пусто, приветствие без имени), дата рождения
(системный date picker; без неё аркан не считается, предложим позже в профиле). Отдельной кнопки
«пропустить» нет — подпись CTA меняется сама: дата выбрана → «ОТКРЫТЬ МОЙ АРКАН», не выбрана →
«ПРОДОЛЖИТЬ» (шаг 3 пропускается).
**Шаг 3 — аркан рождения.** Расчёт: сумма всех цифр даты ДД.ММ.ГГГГ; если >22 — складывать цифры результата
повторно до ≤22; 22=Дурак(0). Показ: карта (парение, свечение) + название + 1–2 фразы «ваш путь»
(блок `birth_path` у 22 старших арканов) + CTA «УЗНАТЬ БОЛЬШЕ ОБО МНЕ» → страница карты.
Завершение онбординга уводит на таб «Сегодня» сам гард; страница аркана открывается поверх него,
поэтому «назад» с неё ведёт на «Сегодня», а не обратно в онбординг.
Данные: имя, дата, ID аркана — в AsyncStorage (store.profile).
Разрешение на пуши НЕ спрашивать здесь (только после первой карты дня, см. §1).

## 1. Сегодня ✅→🔨 (доводка: backlog 01, рефлексия: 06)

Главный экран, открывается первым. Композиция сверху вниз (эталон: вкладка «Сегодня» макета):
overline-дата («ПЯТНИЦА · 8 АВГУСТА») → заголовок «Карта дня» → разделитель со звездой → строка луны
(«☽ Растущая луна · 15-й лунный день», расчёт локальный) → пилюли: серия 🔥 N дней + уровень/XP-полоса →
карта в двух вращающихся кольцах → [после открытия] название + аркан → панель «Значение дня» (текст
day_card) → CTA «Изучить карту» → [вечером] блок рефлексии.

**Поведение карты.** До открытия: рубашка (эмблема + «нажми, чтобы открыть»), парение ±6px. Тап →
хаптика Heavy → 3D-переворот 850мс → хаптика Success → появляются название/значение/CTA (каскад).
Карта детерминирована датой (все видят разные — сид от даты+установки), 1 раз в день, повторный тап
игнорируется. Закрыл приложение → карта та же (история в store).
**Серия.** Открыл карту сегодня и вчера → +1; пропустил день → сброс в 1 (после backlog 10 — заморозка:
1 авто-заморозка/мес, пуш «серия спасена»). Первое открытие за день = единственное, что двигает серию.
**Первый запуск:** серия 0, подсказка-стрелка к карте. **После первой карты ✅(06б):** прелюдия
«Напомнить утром?» с кнопками «Напомнить» / «Не сейчас» появляется сразу после завершения
переворота карты (показывается один раз за всё время, флаг `settings.pushAsked`); «Напомнить»
открывает системный диалог разрешения. Отказ не переспрашиваем — включить можно в настройках.
**Рефлексия ✅:** с 18:00 под значением появляется панель «Как прошёл день с этой картой?» —
три кнопки (Отозвалась/Отчасти/Не отозвалась) + поле заметки; ответ сохраняется в историю; пуш
в 21:00 ✅(06б), если не отвечено (правила и приоритеты — logic-spec §8). Ответ меняет панель
на «записано ✓» + заметка. Блок живёт внутри той же панели, что и заметка о дне: до 18:00 это
«Заметка о дне», после — «Как прошёл день» с вопросом и кнопками над плашкой.

## 2. Курс 🔨 (путь: 07, движок: 08)

**Экран курса** = вертикальный «путь» (эталон: вкладка «Курс»): шапка модуля (название, прогресс %,
«N УРОКОВ · M КАРТ») → извилистая пунктирная тропа с узлами-уроками. Узел: пройден (✓, контур success),
текущий (золотой, пульсирующее кольцо + чип «НАЧАТЬ УРОК»), заблокирован (замок, opacity 0.55).
Тап по текущему → экран урока; по заблокированному → покачивание замка + хаптика Warning; по пройденному →
урок в режиме повторения (+2 XP, не чаще раза в день — logic-spec §4). Модули листаются скроллом; платные (М3+) — замок на шапке
(до подписки в v1.1 — все бесплатны).
**Экран урока ✅(08):** прогресс-бар (шаг X/N, все шаги) → карточки теории (course.json →
lessons[].theory, Cormorant, листание «Далее»; 3–5 страниц (абзацы группируются под бюджет
~700 символов) → разбор карт: по странице на карту урока — изображение + название + 4 ключевых
слова из cards.json (у уроков без карт шага нет) → викторина 5 вопросов (перемешиваются только
варианты, порядок вопросов фиксированный; тип card — с изображением карты; верный → зелёная
рамка + хаптика Light; неверный → красная + правильный подсвечивается через 400мс + хаптика
Error, счёт ошибок не блокирует; после ответа — пояснение explain и «Далее») → финал:
«+N XP» (счётчик катится), конфетти, прогресс модуля («ПРОЙДЕНО N ИЗ M УРОКОВ МОДУЛЯ»
с полосой), CTA «Дальше по пути». XP: 10 за урок, минус 2 за каждую ошибку, минимум 4;
повтор +2 не чаще раза в день. Выход посреди урока → прогресс шага не сохраняется (урок
короткий). Уроки без контента (М3+) — «Урок готовится», завершить нельзя.
**Данные:** прогресс уроков/XP/уровень в AsyncStorage. Уровни: 1=0, 2=50, 3=150, 4=300, 5=500 XP (дальше +250).

## 3. Карты (справочник) ✅→🔨 (доводка: 04)

Заголовок «78 карт» + overline «СПРАВОЧНИК · РАЙДЕР–УЭЙТ 1909» → поиск (SCROLL-AWARE панель —
решение 11.08, задача 04е, заменило липкую: в покое поиск+чипы лежат в потоке шапки и уезжают
со скроллом, жест вверх на глубине >140px выводит компактную панель сверху экрана на стекле
`glass`, повторный тап по табу = прокрутка к началу; ищем по имени, по ключевым
словам карты (`keywords` текущего языка — новичок помнит смысл, а не имя; решение 10.08)
И по скрытым поисковым синонимам (`search`, задача 04г: «расставание», «долги», «выгорание» —
эти слова в интерфейсе не показываются), мгновенная
фильтрация без учёта регистра и «ё/е», С УЧЁТОМ СЛОВОФОРМ (задача 04з: «работе» находит то же,
что «работа»; сравниваются слова без окончаний, поэтому подстрока в середине слова больше
не срабатывает — «рост» не выдаёт «щедрость» и «мудрость»), первый введённый символ сбрасывает чип на «Все»,
пустой результат: «Такой карты нет — проверьте написание») → чипы-фильтры (Все/Старшие/
Жезлы/Кубки/Мечи/Пентакли; без счётчиков — решение 10.08 в пользу макета: короткие подписи влезают
в одну строку с горизонтальной прокруткой; активный — золотой) → сетка 3 колонки (миниатюра
с рамкой + название). Тап → страница карты. Бейдж «Изучено ✓» ✅(08) на картах пройденных уроков —
появится вместе с движком уроков, раньше его нечем наполнить (решение 10.08).
Скелетоны при первом рендере ✅ (скелетон под каждой миниатюрой, пока грузится изображение).

**Страница карты ✅ (03, реализовано 10.08):** кнопка «‹ ВСЕ КАРТЫ» → герой-блок: изображение слева
(парение ±8px/4.5с, рамка, виньетка-свечение) + номер/аркан/масть + название (Cormorant 26) + чипы
ключевых слов → вкладки сфер (Общее/Любовь/Работа/Финансы/Здоровье — переключение с fade 130/350мс,
гаснет и проявляется ВСЁ тело вкладки целиком) → **тело вкладки ✅(39, решение редактора 15.08):**
на «Общем» — Общее значение → Перевёрнутая → Как карта дня → Символика → «Ваша история с картой»
(если выпадала; ✅ 05); на вкладке сферы — РОВНО два блока: значение сферы и «Перевёрнутая»
с перевёрнутым текстом ЭТОЙ сферы (`<sphere>_reversed`, задача 25) — ни общей перевёрнутой,
ни карты дня, ни символики, ни истории (до 39 общие блоки лежали под всеми вкладками, и перевёрнутая
показывалась дважды: припиской сферы и общим блоком). Каскад появления по макету: блок значения
`d4`, всё остальное тело вкладки одним шагом `d5` → навигация ← → к соседней карте 📋. Если карта = аркан рождения
пользователя — золотой чип «✦ ВАШ АРКАН РОЖДЕНИЯ» ✅ (09) рядом с названием; в узкой колонке героя
он переносится на строку под названием — так задумано, ужимать название ради одной строки не нужно.
**Полноэкранный просмотр ✅(14):** тап по изображению карты (страница карты; карта дня после
переворота) → карта раскрывается на весь экран поверх интерфейса: фон затемняется (scrim 85% + blur),
изображение летит из своей позиции с ПОЛНЫМ оборотом через рубашку («взять карту в руки», motion-spec §15), хаптика Light. Во время просмотра — параллакс от гироскопа: карта отзывается на наклон телефона, блик живёт противофазно (отключается при reduce motion). Внутри: pinch-zoom
до ×3 и панорамирование (рассмотреть детали рисунка), подпись внизу «НАЖМИТЕ, ЧТОБЫ ЗАКРЫТЬ».
Закрытие: тап по фону, свайп вниз (карта «улетает» обратно на своё место) или ✕ в углу.
Перевёрнутая карта в просмотре показывается ПРЯМОЙ (рассматриваем рисунок, а не положение).
Статус-бар скрывается на время просмотра. **Подсказка о просмотре ✅(39):** оба входа (герой
страницы карты, лицевая грань открытой карты дня) несут в правом верхнем углу картинки ярлычок-иконку
`expand-outline` на скриме — той же формы, что бейдж «Изучено ✓» в сетке (общий `CornerBadge`,
design-system §5). Копия карты в просмотре и миниатюры сетки ярлычка не несут; на время просмотра
ярлычок прячется вместе с источником.

**Контекстный блок «Как карта дня» ✅ (реализовано 10.08):** если открытая карта = сегодняшняя карта дня пользователя,
блок поднимается ВЫШЕ вкладок сфер, получает золотую рамку (frame, как «Ваша история») и заголовок
«✦ ВАША КАРТА СЕГОДНЯ»; в остальных случаях лежит на обычном месте обычной панелью. Проверка:
todayDraw()?.cardId === card.id.
Блок со status=todo: «Текст готовится» курсивом (после заполнения базы — не должно встречаться).

## 4. Расклады ✅ (36, реализовано 15.08)

**Список:** 8 раскладов (панель: название + N карт + описание + мини-схема позиций ✅ + PREMIUM-бейдж).
«Карта дня» в списке ведёт на таб «Сегодня». Тап по PREMIUM → шторка «откроется в подписке» (до v1.1
подписки нет — все расклады доступны, бейдж показываем для привыкания). Лимитов на расклады в v1 нет
(решение о лимитах free — вместе с включением подписки).

**Экран расклада — сценарий:**
1. **Настрой:** заголовок + подсказка «Подумайте о своём вопросе» + опциональное поле «Ваш вопрос»
   (сохранится с раскладом). CTA «Разложить карты» → тасование (logic-spec §1а) + хаптика. После
   «Разложить карты» вопрос фиксируется — задан ДО карт.
2. **Открытие:** рубашки по местам, открываются тапом в любом порядке (переворот 500мс + хаптика Light).
   Перевёрнутая карта рисуется вверх ногами (rotate 180°). Под картой — название позиции + имя карты.
3. **Раскладка на экране:** ≤5 карт — по геометрической схеме позиций; 7–10 карт (Подкова, Кельтский
   крест) — ряд ячеек прогресса сверху (открытые подсвечены) + «Открыто X из N» + вертикальная лента
   позиций под ней.
4. **Значения:** после открытия карты в ленте под ней раскрывается блок: «ПОЗИЦИЯ · Карта» +
   текст = general (или reversed, если перевёрнута) из cards.json + ключевые слова. Тап по карте →
   её полная страница. В ленте 7–10 абзац значения — под строкой в той же панели (решение 15.08).
4а. **«Состав расклада»** (после открытия ВСЕХ карт, перед заметкой): 1–4 офлайн-наблюдения по
   правилам logic-spec §1б — нейтральная констатация состава (арканы/масти/перевёрнутые/номиналы) +
   вопрос для размышления. Никакого ИИ, никаких обещаний ИИ в интерфейсе; тон — наблюдение, не совет
   (политика сторов). Пример: «Все три карты — Старшие арканы: расклад о значимых поворотах.
   Спросите себя: какой из них уже начался?»
5. **Финал:** когда открыты ВСЕ карты — панель: поле заметки (если вопрос был — он уже подставлен
   заголовком) + CTA «Сохранить в дневник» (до этого кнопки нет). Выход без сохранения → расклад
   не записывается (подтверждение «Уйти без сохранения?»). «Сохранить в дневник» начисляет +5 XP
   (logic-spec §4).
**Жизненный цикл расклада (что с ним происходит дальше):**
- **Пока открыт экран** — расклад живёт: можно уходить на другие табы и возвращаться, карты на месте
  (черновик в памяти). Полное закрытие приложения → несохранённый черновик пропадает (это норма:
  не сохранил — значит не важен; ничего не пишем без явного «Сохранить»).
- **Выход с экрана с открытыми, но несохранёнными картами** → мягкий вопрос «Уйти без сохранения?
  Расклад исчезнет» (Уйти / Остаться).
- **После «Сохранить в дневник»** → кнопка меняется на «Сохранено ✓», под ней появляется
  «Разложить заново» — новое тасование с чистого листа, включая вопрос (старый расклад уже
  в дневнике, ничего не теряется). Отдельной кнопки «сброс» ДО сохранения нет: перетасовать
  несохранённый расклад нельзя — иначе люди будут тасовать до «хорошего ответа», что против нашей
  философии (расклад честный, карту не перетягивают). Единственный путь к новому раскладу — выйти
  без сохранения (с подтверждением) или сохранить и разложить заново.
- **Повторный вход с экрана списка** → всегда новый расклад с шага «Настрой» (вопрос + тасование).
**Сохранённый расклад в дневнике:** строка среди записей месяца: дата · иконка-«веер» (глиф таба
«Карты», не мини-карта — чтобы отличать от карты дня) · название расклада · первая строка
заметки/вопроса · ✦ справа. Тап → экран расклада в режиме просмотра: все карты открыты, состав
на месте, вопрос и заметка только чтение, тасование недоступно. Фильтр «с заметкой» в дневнике
ловит расклад с заметкой ИЛИ вопросом.

## 5. Профиль ✅→🔨

Сейчас: статистика (серия, карт дня открыто), переключатели темы и языка. Добавляется:
**Дневник 🔨(05):** организация при любом объёме записей (до 365):
- **Полоска распределения** в карточке месяца: тонкий трёхсегментный бар под строкой
  «Отозвалось X из Y» — доли ✓ (success) / ≈ (accent) / ✗ (muted) за месяц. Единственная визуализация
  рефлексий в v1: графики трендов и «процент точности» НЕ делаем — рефлексия должна оставаться мягким
  ритуалом, а не отчётностью (плюс «точность предсказаний» — красный флаг для ревью сторов).
  Календарь-теплокарта месяца — уже в плане 📋 этап 3+.
- **Группировка по месяцам.** Заголовок-навигатор «‹ АВГУСТ 2026 ›» — стрелки листают месяцы
  (только месяцы с записями; пустых секций нет). Под заголовком — карта месяца со статистикой
  рефлексий этого месяца, затем записи месяца (новые сверху).
- **Порции.** Показываются все записи выбранного месяца (макс ~31 — виртуализация FlatList,
  скролл не тормозит). Бесконечной ленты за всё время НЕТ — навигация только через месяцы.
- **Фильтр-чипы** над лентой: Все / ✓ / ≈ / ✗ / «с заметкой» — фильтруют текущий месяц;
  счётчик в чипе («✓ 12»). Сброс при смене месяца.
- **Строка записи:** дата (день недели + число), мини-карта, отметка, первая строка заметки

## 6. Сквозное

**Темы:** тёмная (базовая) и светлая, мгновенное переключение, персист. **Языки:** список из четырёх
(RU/EN/ES/PT), названия — эндонимами, выбор в настройках; при первой установке — язык устройства,
если он есть среди доступных, иначе английский; язык без UI-строк в списке не показывается;
контент, ещё не переведённый на выбранный язык, показывается по-английски. **Офлайн:** всё работает
без сети всегда (контент в бандле).
**Данные пользователя:** только локально (AsyncStorage; SQLite с задачи 05); ничего не уходит на сервер.
**Пуши:** максимум 2/день, тон — интрига без вины; точные тексты — в master-plan §3.1-Р.
**Ошибки:** приложение никогда не показывает красный экран пользователю — ErrorBoundary с мягкой
заглушкой («Карты перемешались. Попробуйте ещё раз»).
