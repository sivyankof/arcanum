## 0. Онбординг 🔨 (backlog 09)

Показывается один раз при первом запуске (флаг в AsyncStorage).

**Шаг 1 — приветствие.** Эмблема-звезда (вращение 40s), «Arcanum», подзаголовок «Научитесь читать таро —
по 5 минут в день». CTA «НАЧАТЬ ПУТЬ». Точки-прогресс (1/3).
**Шаг 2 — о вас.** Поля: имя (текст, необязательное — если пусто, приветствие без имени), дата рождения
(нативный date picker, обязательное для аркана рождения; кнопка «пропустить» → аркан не считается,
предложим позже в профиле). CTA «ОТКРЫТЬ МОЙ АРКАН» (или «ПРОДОЛЖИТЬ» при пропуске даты).
**Шаг 3 — аркан рождения.** Расчёт: сумма всех цифр даты ДД.ММ.ГГГГ; если >22 — складывать цифры результата
повторно до ≤22; 22=Дурак(0). Показ: карта с анимацией появления + название + 1–2 фразы «ваш путь» +
CTA «УЗНАТЬ БОЛЬШЕ» → страница карты. После онбординга → таб «Сегодня».
Данные: имя, дата, ID аркана — в AsyncStorage (store.profile).
Разрешение на пуши НЕ спрашивать здесь (только после первой карты дня, см. §1).

## 1. Сегодня ✅→🔨 (доводка: backlog 01, рефлексия: 06)

Главный экран, открывается первым. Композиция сверху вниз (эталон: вкладка «Сегодня» макета):
overline-дата («ПЯТНИЦА · 8 АВГУСТА») → заголовок «Карта дня» → разделитель со звездой → строка луны
(«☽ Растущая луна · 15-й лунный день», расчёт локальный) → пилюли: серия 🔥 N дней + уровень/XP-полоса →
карта в двух вращающихся кольцах → [после открытия] название + аркан → панель «Значение дня» (текст
day_card) → CTA «Изучить карту» → [вечером] блок рефлексии.

**Поведение карты.** До открытия: рубашка (эмблема + «нажми, чтобы открыть»), парение ±6px. Тап →
хаптика Heavy → 3D-переворот 850мс → хаптика Success → появляются название/значение/CTA (каскад).
Карта детерминирована датой (все видят разные — сид от даты+установки), 1 раз в день, повторный тап
игнорируется. Закрыл приложение → карта та же (история в store).
**Серия.** Открыл карту сегодня и вчера → +1; пропустил день → сброс в 1 (после backlog 10 — заморозка:
1 авто-заморозка/мес, пуш «серия спасена»). Первое открытие за день = единственное, что двигает серию.
**Первый запуск:** серия 0, подсказка-стрелка к карте. **После первой карты:** системный запрос пушей
с прелюдией («Напомнить о карте завтра утром?» → кнопка → системный диалог).
**Рефлексия 🔨(06):** с 18:00 под значением появляется панель «Как прошёл день с этой картой?» —
три кнопки (Сбылось/Отчасти/Мимо) + поле заметки; ответ сохраняется в историю; пуш в 21:00, если
не отвечено. Ответ меняет панель на «записано ✓» + заметка.

## 2. Курс 🔨 (путь: 07, движок: 08)

**Экран курса** = вертикальный «путь» (эталон: вкладка «Курс»): шапка модуля (название, прогресс %,
«N УРОКОВ · M КАРТ») → извилистая пунктирная тропа с узлами-уроками. Узел: пройден (✓, контур success),
текущий (золотой, пульсирующее кольцо + чип «НАЧАТЬ УРОК»), заблокирован (замок, opacity 0.55).
Тап по текущему → экран урока; по заблокированному → покачивание замка + хаптика Warning; по пройденному →
урок в режиме повторения (без XP). Модули листаются скроллом; платные (М3+) — замок на шапке
(до подписки в v1.1 — все бесплатны).
**Экран урока 🔨(08):** прогресс-бар (шаг X/N) → карточки теории (course.json → lessons[].theory,
Cormorant, листание «Далее») → викторина 3–5 вопросов (варианты-панели; верный → зелёная рамка +
хаптика Light; неверный → красная + правильный подсвечивается, счёт ошибок не блокирует) → финал:
«+N XP» (счётчик катится), конфетти, серия уроков, CTA «Дальше по пути». XP: 10 за урок, минус 2 за
каждую ошибку, минимум 4. Выход посреди урока → прогресс шага не сохраняется (урок короткий).
**Данные:** прогресс уроков/XP/уровень в AsyncStorage. Уровни: 1=0, 2=50, 3=150, 4=300, 5=500 XP (дальше +250).

## 3. Карты (справочник) ✅→🔨 (доводка: 04)

Заголовок «78 карт» + overline «СПРАВОЧНИК · РАЙДЕР–УЭЙТ 1909» → поиск 🔨 (по имени, мгновенная
фильтрация, пустой результат: «Такой карты нет — проверьте написание») → чипы-фильтры (Все/Старшие/
Жезлы/Кубки/Мечи/Пентакли; счётчики 78/22/14×4; активный — золотой) → сетка 3 колонки (миниатюра
с рамкой + название). Тап → страница карты. Бейдж «Изучено ✓» 🔨 на картах пройденных уроков.
Скелетоны при первом рендере 🔨.

**Страница карты ✅→🔨(03):** герой-блок: изображение слева (парение, рамка, виньетка-свечение 🔨) +
номер/аркан/масть + название (Cormorant 26–28) + чипы ключевых слов → вкладки сфер 🔨 (Общее/Любовь/
Работа/Финансы/Здоровье — переключение с fade 130мс; сейчас блоки простынёй — заменить) → под вкладками:
Перевёрнутая, Как карта дня, Символика (всегда видны) → навигация ← → к соседней карте 📋.
Блок со status=todo: «Текст готовится» курсивом (после заполнения базы — не должно встречаться).

## 6. Сквозное

**Темы:** тёмная (базовая) и светлая, мгновенное переключение, персист. **Языки:** RU (основной)/EN,
меняет весь контент включая тексты карт. **Офлайн:** всё работает без сети всегда (контент в бандле).
**Данные пользователя:** только локально (AsyncStorage; SQLite с задачи 05); ничего не уходит на сервер.
**Пуши:** максимум 2/день, тон — интрига без вины; точные тексты — в master-plan §3.1-Р.
**Ошибки:** приложение никогда не показывает красный экран пользователю — ErrorBoundary с мягкой
заглушкой («Карты перемешались. Попробуйте ещё раз»).
