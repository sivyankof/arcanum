# Спека 39 — страница карты: вкладки без общих блоков + ярлычок «можно увеличить»

Статус: спека и план согласованы 15.08 (брейншторм с Артёмом, решения ниже). Реализация —
сессия на Opus 5, код по шагам плана отдаётся sonnet-сабагентам; ветка `feat/39-card-page-notes`,
merge после лайв-проверки.

Повод — показ приложения редактору (жене) 15.08, два замечания:

1. На вкладках сфер (Любовь/Работа/Финансы/Здоровье) под текстом сферы лежат ЕЩЁ И общие блоки —
   «Перевёрнутая», «Как карта дня», «Символика». Перевёрнутая при этом показана дважды: припиской
   сферы внутри блока (задача 25) и общим блоком ниже. Читатель, выбравший «Любовь», должен видеть
   только любовь.
2. Тап по картинке карты открывает полноэкранный просмотр (задача 14), но об этом ничто не говорит —
   нужен маленький ярлычок в углу картинки, в стиле бейджа «ИЗУЧЕНО ✓» из справочника.

## Решения (брейншторм 15.08, ответы Артёма)

| Вопрос | Решение |
|---|---|
| Перевёрнутая на вкладках сфер | **Отдельный блок-панель «ПЕРЕВЁРНУТАЯ»** под блоком сферы, с текстом `<сфера>_reversed` — ровно как на «Общем» стоит общая перевёрнутая. Приписка-с-разделителем из задачи 25 уходит: она была нужна, только пока общая перевёрнутая лежала ниже на той же вкладке. |
| «Ваша история с картой» | **Только на «Общем»** — буквально «всё остальное только на первой вкладке». |
| Содержимое ярлычка | **Только иконка** Ionicons `expand-outline`, без текста (герой всего 128px, а подпись пришлось бы переводить на 4 языка). |
| Угол | **Правый верхний** — та же «полка», что у «ИЗУЧЕНО ✓» в сетке; низ карт Райдер–Уэйт занят печатным названием. |

## Цель

- На каждой вкладке страницы карты — только то, что относится к этой вкладке. Ритм одинаковый
  на всех пяти: **значение → перевёрнутая**; «Общее» дополнительно несёт всё, что относится к карте
  целиком (как карта дня, символика, ваша история).
- Пользователь видит, что картинку можно взять в руки: ярлычок в углу обоих входов в лайтбокс
  (герой страницы карты, открытая карта дня).

## Что делаем

### Часть А — вкладки страницы карты (`app/card/[id].tsx`)

Состав вкладок (сверху вниз, под пилюлей вкладок):

| Вкладка | Блоки |
|---|---|
| **Общее** | «Общее значение» (`general`) → «Перевёрнутая» (`reversed`) → «Как карта дня» (`day_card`; если карта = сегодняшняя карта дня — блок уже поднят над вкладками золотой рамкой, внизу не дублируется, как сейчас) → «Символика» (`symbolism`) → «Ваша история с картой» (только если карта выпадала, как сейчас) |
| **Любовь / Работа / Финансы / Здоровье** | «Значение в <сфере>» (`<sphere>`) → «Перевёрнутая» (`<sphere>_reversed`). Больше НИЧЕГО. |

- Контекстный блок «✦ ВАША КАРТА СЕГОДНЯ» над вкладками — без изменений, виден на всех вкладках
  (он выше пилюли, к вкладкам не относится).
- Порядок на «Общем» — как в product-spec §3 и в коде сейчас: символика, потом история. ⚠️ В макете
  история стоит ПЕРЕД символикой — расхождение макета со спекой существовало до этой задачи
  (правило 6а-0: реализуем по спеке, макет не копировать); при дорисовке макета (шаг 7) блок истории
  переставить под символику, чтобы порядок сошёлся.
- Заголовок блока перевёрнутой на всех вкладках один — `card.reversed` («Перевёрнутая»); сфера ясна
  из активной вкладки. Новых строк i18n нет.
- Блок со статусом `todo` показывает «Текст готовится» через существующий `blockOf` — как все
  остальные блоки страницы (особый случай «спрятать приписку, если todo» из задачи 25 больше не нужен:
  корпус 958/958 reviewed, а полноценный блок обязан вести себя как соседи).
- **Смена вкладки** — тот же fade 130 мс out → подмена → 350 мс in (`fade` shared value уже есть),
  но гаснет и проявляется **всё тело вкладки целиком** (все блоки под пилюлей), а не только контент
  блока сферы: число панелей на вкладках разное, панели появляются/исчезают в момент нуля прозрачности.
  Высота меняется без анимации в тот же момент (прецедент — кнопки рефлексии, design-system §5).
- **Каскад появления (FadeUp)** — как в макете: блок значения `d4` (`idxSphere`), **всё остальное
  тело вкладки одним шагом `d5`** (`idxReversed`) — в макете `.block fadeup d5` стоит у перевёрнутой,
  карты дня, истории и символики одинаково; сейчас код даёт символике 5, карте дня 4 — приводим к макету.
  ⚠️ Ловушка: `FadeUp` играет полный вход (450 мс, подъём 14px, задержка `index × 70`) при
  МОНТИРОВАНИИ на сфокусированном экране. Если обернуть карту дня/символику/историю каждую в свой
  `FadeUp`, то при возврате на «Общее» они будут всплывать мини-каскадом на каждом переключении.
  Поэтому обёрток `FadeUp` в теле вкладки ровно ДВЕ и обе смонтированы всегда: первая вокруг блока
  значения, вторая вокруг перевёрнутой + условных блоков «Общего» (условие внутри неё, на children).
- `Block.contentStyle` после правки не используется нигде → проп, `Animated.View` внутри `Block`
  и импорт reanimated убрать, комментарий шапки `Block.tsx` обновить (панель не анимируется, точка).
- Стили `reversedDivider` / `reversedLabel` / `reversedText` в `[id].tsx` — удалить вместе с припиской.

### Часть Б — ярлычок «можно увеличить» (новый общий `CornerBadge`)

- Новый компонент `src/components/CornerBadge.tsx` — угловой бейдж поверх картинки. Это **второе
  появление** одной и той же формы (первое — «ИЗУЧЕНО ✓» в `app/(tabs)/cards.tsx`, стили `st.learned`
  / `st.learnedTxt`), поэтому по правилу «2+ раза → выносить» бейдж справочника переводится на него же.
  Пропсы: `label?: string` (текстовый вариант — «ИЗУЧЕНО ✓») **или** `icon?: <имя Ionicons>`
  (иконочный — `expand-outline`); `style?` для редких поправок. Геометрия — из design-system §5
  (`.st2` эталона): absolute, `top: 6, right: 6`, фон `rgba(0,0,0,0.4)` (скрим поверх фото —
  литерал, как тень миниатюры, НЕ токен темы), `borderRadius: radius.s` (8), в стиле
  `pointerEvents: 'none'` (свойство внутри стиля, не пропом — правило проекта). Текстовый вариант:
  паддинг 2×6, `Txt` 8/700/ls 0.5 цветом `t.accent2` (без изменений против сейчас). Иконочный
  вариант: паддинг 3 со всех сторон, `Ionicons` size 12 цветом `t.accent2` (outline-вариант — §6).
- Куда ставится иконка `expand-outline`:
  1. **Герой страницы карты** — внутри `st.imClip` (обрезка с рамкой) ПОСЛЕ `<Image>`: летит вместе
     с героем из сетки, парит вместе с ним, на время просмотра прячется вместе с ним (обёртка
     `hidden`). Замер `heroRef.measureInWindow` не меняется — бейдж внутри обрезки.
  2. **Карта дня** (`app/(tabs)/index.tsx`) — внутри `faceClip` ЛИЦЕВОЙ грани после `<Image>` и
     блика (поверх блика: скрим не должен «зажигаться»). Без условия по `drawn`: до переворота
     лицевая грань повёрнута на 180° с `backfaceVisibility: hidden` и не видна; на время просмотра
     грань прячется целиком (`st.hidden`) — бейдж вместе с ней.
- Копия карты в `CardLightbox` ярлычка НЕ несёт (это «карта в руках», а не превью). Исчезновение
  ярлычка в момент тапа — ожидаемо: источник прячется, копия летит.
- В сетке справочника ярлычка НЕТ (тап там ведёт на страницу карты, а не в просмотр).
- Размер один для обоих мест (12px иконка, инсет 6): согласованность важнее подгонки под 230-px
  карту дня; на лайв-проверке при желании поправить — одним числом в компоненте.

## Что НЕ делаем

- Контент не трогаем (`cards.json` без изменений; статусы 958/958 reviewed остаются).
- Общий блок «Перевёрнутая» на «Общем» остаётся общим — приписки сфер его не заменяют.
- Персист, стор, i18n не меняются (новых строк нет; `card.viewerOpen` уже есть как
  accessibilityLabel героя). Persist version остаётся 8.
- Ярлычок не анимируем (ни пульса, ни боба): anti-чеклист motion-spec запрещает бесконечные
  пульсации вне явного списка исключений, а карта в обоих местах уже живёт своим циклом (парение
  героя, покачивание карты дня) — второй живой элемент рядом «это дёшево».
- Навигацию ← → к соседней карте (📋 product-spec) не делаем.
- Не меняем поведение полноэкранного просмотра (задача 14 закрыта).

- Панель блока — `Block` без изменений: `panel` / `line` 1px / radius `l` / паддинг `spacing.l`,

  `accent2`, паддинг 2×6; иконка 12 `accent2`, паддинг 3.
