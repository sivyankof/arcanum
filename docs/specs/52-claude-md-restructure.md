# 52 · Реструктуризация CLAUDE.md без потери содержимого

**Статус: ЗАКРЫТА 22.08.2026** (документы, кода нет; лайв-проверка не требуется).

## Цель

CLAUDE.md грузится в контекст каждой сессии и каждого сабагента целиком. На 22.08 он весил
~280 КБ (≈168 тыс. знаков, грубо 55–70 тыс. токенов), из них **95 %** — хроника задач 01–50
с 211 ⚠️-уроками, и только 5 % — инструкции (процесс, правила, таблица доков, структура). Ключевые
правила тонули в хронике, одни и те же уроки повторялись до 7 раз, заголовок «Статус (на 12 августа)»
устарел. Задача — вынести хронику и уроки в документы, сохранив **каждый** абзац, и оставить
в CLAUDE.md только то, что нужно в каждой сессии.

## Что делаем

1. `docs/changelog.md` — **дословный** перенос разделов «Статус» и «Ближайшие задачи» (единым блоком,
   без правок) + раздел «Записи после 22.08.2026» для новых задач.
2. `docs/lessons.md` — все ⚠️-уроки по 13 темам (стор/persist; веб ≠ натив; анимации; вёрстка
   и контраст; навигация; время и пуши; i18n; тесты; веб-проверка; контент-конвейер; редактура;
   процесс и окружение; алгоритмы). Текст каждого урока — дословно, с пометкой задачи-источника;
   правило, подтверждённое несколько раз, — под одним заголовком со ВСЕМИ подтверждениями (каждое несёт
   свой пример). Два урока, стоявшие ⚠️ внутри обычных абзацев (`year: 'numeric'`, вложенный `reviewDay`),
   добавлены отдельно. Хвосты хроники, приклеившиеся к ⚠️-абзацам (счёт тестов, описание макета,
   `pickPhrase`, `useTabTopRef`, побочные сдвиги задачи 50), в lessons.md срезаны — они есть в changelog.
3. CLAUDE.md: шапка (контекст, процесс, правила, таблица доков, структура) сохранена построчно, кроме
   трёх намеренных правок: шаг 0 процесса «прочитай уроки по теме», шаг 7 — куда теперь писать хронику
   и уроки, строка про `content/*.json` — четыре языка вместо «двуязычные ru/en». Добавлены: две строки
   в таблицу доков (lessons, changelog), **13 сквозных правил** (выжимка повторявшихся уроков), короткий
   «Статус» на 22.08 (сделано, цифры, незавершённая ветка 51, хвосты, решения «чтобы не возвращались»),
   указатель общих модулей и компонентов (для правила DRY).
4. backlog.md: запись задачи, правило синхронизации доков обновлено.

## Что НЕ делаем

- Не переписываем уроки своими словами и не удаляем повторы (только группируем).
- Не трогаем AGENTS.md (27 КБ, ≈6 тыс. токенов — отдельный кандидат на ужатие, не в этой задаче).
- Не трогаем ветку `feat/51-moon-spreads`: работа сделана в worktree на `main`, пока ветка в работе.
