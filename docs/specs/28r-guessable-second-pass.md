# 28р · Второй заход по разделу C списка 28е: 35 вопросов «только суждение решателя»

Статус: **спека готова (23.08), ждёт «ок» Артёма**. Последний открытый хвост задачи 28е (CLAUDE.md
«Открытые хвосты»): доказанное ядро (26) и «только механика» (7) исправлены 21.08 и перезалиты на
es/pt задачей 28п (23.08); раздел **C** — 35 вопросов, которые пометили ТОЛЬКО слепые решатели,
без механической опоры, — по записи замера «перечитать вторым заходом, разбирать по одному, а не

es/pt изменённых вариантов — Cowork по промту, который пишет эта задача.

## Цель

Каждый из 35 вопросов раздела C получает **вердикт с обоснованием** (дефект / дидактика / рационализация),
настоящие дефекты исправлены правкой дистракторов, и после правки оба слоя замера (механика + слепой
прогон) не хуже, чем до неё. Список 28е закрыт целиком; в CLAUDE.md хвост 28е снимается.

## Чем этот заход отличается от 21.08 (урок замера)

Раздел C — это пометки агентов, которые **не могут честно «забыть» таро** (`docs/lessons.md` §11,
«Агент, знающий предмет…»): из 61 пометки НИ ОДНА не промахнулась мимо верного ответа, то есть часть
из них — рационализация задним числом. Поэтому здесь **правка списком запрещена**: сначала вердикт
по каждому вопросу, и только для вердикта «дефект» — правка. Ожидание сессии: дефектов окажется
порядка 10–15 из 35, остальное — дидактика и рационализация; точное число — результат задачи, а не
цель. ⚠️ Если вердикт «дефект» получат все 35 — это признак, что разбор не состоялся.

## Классификация вердиктов (записать в таблицу отчёта по каждому вопросу)

| вердикт | признак | действие |
|---|---|---|
| **дефект / offtopic** | дистрактор не отвечает на заданный вопрос, отрицает его посылку («Чем отличается…» → «Ничем»), говорит о карте/масти, которой в вопросе нет | переписать дистрактор: ответ НА вопрос, но неверный по содержанию |
| **дефект / absurd** | дистрактор нелеп для любого взрослого без знания таро (нарушает причинность, противоречит здравому смыслу, «солнце быстрее гаснет») | переписать: правдоподобное заблуждение новичка |
| **дефект / absolute** | в дистракторах абсолют («все», «только», «каждую ночь», «никогда»), которого НЕТ в верном, — и именно он, а не содержание, выдаёт ответ | снять абсолют, оставить ошибку по существу |
| **дидактика** | дистрактор воспроизводит расхожий миф о таро (предсказание, дар, ритуал, «обидеть колоду») — в развенчании и состоит вопрос (урок «Дидактика ≠ дефект») | **оставить**, записать «миф: …» |
| **асимметрия жанра** | верный ответ структурно осторожнее неверных, потому что курс учит, что таро не предсказывает; убрать это = сделать верный неверным | **оставить** |
| **рационализация** | пометка решателя опирается на знание карты («Императрица — не про борьбу»), без которого выбор не очевиден | **оставить** |

Маркер «absolute» в разделе C — без механической опоры: счётчик 21.08 (те же слова) этих вопросов
НЕ пометил, значит абсолют либо есть и в верном тоже, либо не является решающим признаком. Для таких
вопросов вердикт «дефект» требует второго аргумента (offtopic/absurd), одного слова «все» мало.

## Правила правки (те же, что 28е, — не пересказывать, а выполнять)

1. Правится **только дистрактор**. Текст вопроса, верный вариант, `correct`, `explain` — не трогать
   ни разу; исключение — фактическая ошибка в верном (как m1l2 в L-4), о ней отдельный флаг Артёму,
   а не правка.
2. **ru и en синхронно**, одним коммитом, одинаковым смыслом; es/pt **не трогать** (их перезаливает
   Cowork с пары ru+en, правка по месту оставляет следы старой формулировки).
3. Дистрактор после правки: отвечает на вопрос; правдоподобен для новичка; отвергается знающим ПО
   СОДЕРЖАНИЮ; без абсолютов, которых нет в верном; не длиннее верного настолько, чтобы верный
   перестал быть не-самым-длинным там, где это уже так (правило длин: верный — единственный самый
   длинный не более чем в 2 вопросах урока; коридор 1.3×; `card`-вопросы вне правила, кроме М6).
4. Новый дистрактор не повторяет другой вариант того же вопроса и не сближается с верным (проверки
   9 и 10 `check_edits.py`).
5. Каждая правка — запись «было → стало» в `docs/specs/28r-changed-addresses.md` (формат
   `docs/specs/28e-changed-addresses.md`: адрес `m2l1-q2[1].ru`).

## Механика (второй слой) — оформить скриптом, а не считать в голове

21.08 механический счётчик (абсолютные маркеры + длины) существовал только в сессии и не сохранён;
страж «верный не тронут» — тоже. Это нарушает правило проекта «инструмент проверки живёт в репо
и повторяется». Поэтому:

- `scripts/check_quiz_guess.py` (новый, Python ≥3.10, без зависимостей, читает `content/quiz-*.json`):
  - **маркеры**: список абсолютов ru/en (`всегда|никогда|всех?|всё|полностью|только|каждую|любой|ничего|
    без исключений|либо … либо` / `always|never|all|every|only|completely|nothing|entirely|either … or`;
    список — в докстроке с калибровкой числом ложных срабатываний, приём `dict_es.py`); сигнал, когда
    маркеры есть в дистракторах и ОТСУТСТВУЮТ в верном;
  - **длина**: верный ≥1.3× второго по длине; и «верный единственный самый длинный» больше чем в 2
    вопросах урока (без запаса — как `courseContent.test.ts`); `card`-вопросы вне правила длин,
    кроме М6 (урок задачи 26);
  - `--against HEAD` (или путь к файлу-снимку): **страж** — у каждого вопроса текст верного варианта
    (ru и en), `correct`, `q`, `explain` совпадают с HEAD; расхождение печатается по имени вопроса,
    код 1. Это замена ad-hoc стража 21.08.
  - Печатает отчёт (числа по модулям + адреса), код 0/1. **Калибровка**: прогон на HEAD до правок
    обязан дать 0 сигналов маркеров/длин (21.08 довели до нуля) — если даёт больше, сначала понять,
    чем отличается счётчик, и записать в докстроку. Мутация: подсадить «всегда» в дистрактор
    `m1l1-q1[0].ru` в копии файла — ловится поимённо; поменять `correct` — страж ловит.
- `check_canon.py --scope course` (проверка 11 длин вариантов) и `check_edits.py docs/specs/28r-changed-addresses.md`
  — оба после правок, как на 28е/28п; `npm test` — контракт `courseContent.test.ts`.

## Слепой прогон (первый слой) — только на изменённых вопросах

После правок: один агент-решатель (sonnet, свежий контекст, без доступа к репозиторию: только текст
вопроса и три варианта, без ключа) решает ТОЛЬКО изменённые вопросы и помечает «решается вслепую»
с признаком. Пометки читать по правилу 21.08: ссылка на миф → дидактика; ссылка на осторожность →
асимметрия жанра; **offtopic/absurd — настоящие**, чинить вторым проходом. Итог — числа в отчёте
(«помечено N из M, настоящих K, исправлено K»).
