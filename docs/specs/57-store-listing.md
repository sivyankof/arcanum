# 57 · Тексты для сторов на четырёх языках (черновик к сабмиту)

Статус: **спека готова (23.08), ждёт «ок» Артёма**. Пункт release-checklist «Магазины: тексты и
материалы» — единственная его часть, которую можно сделать без аккаунтов. Результат — один файл
`docs/store-listing.md` с черновиками на ru/en/es/pt; вычитка редактором (жена) и нейтивами (Cowork,
волна вместе с 54) — после. Скриншоты сторов в эту задачу НЕ входят (нужен девайс/симулятор).

## Цель

Когда аккаунты заведены, тексты для App Store Connect и Play Console копируются из одного файла,
а не пишутся в форме под таймером. Все лимиты символов соблюдены и проверены тестом.

## Решения
- **Д1. Название**: базовый вариант release-checklist — «Arcanum — обучение таро» (≤30). На каждом языке
  своё: `Arcanum — Tarot Learning` / `Arcanum — Aprende Tarot` / `Arcanum — Aprenda Tarô`. Артём
  выбирает финал; в файле — 2–3 кандидата на язык с числом символов.
- **Д2. Состав полей** (по сторам, лимиты — в скобках, считать в символах Unicode):
  - iOS: название (30), подзаголовок (30), промо-текст (170), описание (4000), ключевые слова (100,
    через запятую, без пробелов после запятой, без повторов слов из названия/подзаголовка), «что
    нового» (4000) для 1.0 — две строки.
  - Google Play: название (30), короткое описание (80), полное описание (4000).
  - RuStore: название, короткое и полное описание — те же, что Google (ru).
  - Общее: категория — Образование (вторичная — Стиль жизни), возраст 12+/аналог, заметки для
    ревьюера (en): офлайн, без аккаунтов, без аналитики, подписка через RevenueCat, демо-доступ к
    premium — DEV-тумблер не в релизе, поэтому описать, что закрыто за подпиской.
- **Д3. Тон и правила текста** — `docs/content-guide.md` «Тон» + «Тексты интерфейса»: без обещаний
  предсказания и «высших сил» (рамка предсказания — тот же класс, что в каноне карт: стор-текст
  тоже читает ревьюер Apple по 1.4.1/5.1 и пользователь), без медицинских/финансовых гарантий;
  факты о приложении — только те, что есть в коде (78 карт, 32 урока в 6 модулях, 10 раскладов,
  флеш-карты SM-2, лунный календарь, дневник, 4 языка, офлайн, бэкап). Каждый факт — с ссылкой
  в файле на источник (product-spec/код), чтобы вычитка не гадала.
- **Д4. Ключевые слова** — по языкам, 100 символов: семантика «обучение таро / значения карт /
  карта дня / расклады / флеш-карты / таро для начинающих». Не вписывать бренды конкурентов и слово
  «бесплатно» (правило App Store). Русский набор — ещё и для RuStore.
- **Д5. Контракт-тест лимитов** `src/lib/__tests__/storeListing.test.ts`: парсит `docs/store-listing.md`
  (поля размечены заголовками `### <язык> · <поле> (<лимит>)`), проверяет длину каждого блока
  ≤ лимита, ключевые слова — без пробелов после запятых и без дублей, описания без запрещённых слов
  из короткого списка (`гарант`, `предскаж`, `вылеч`, `guarantee`, `predict`, `cure`, `garantiz`,
  `predic`, `cura`). Красный прогон: удлинить короткое описание до 81 символа — тест падает.
  Это тест на документ, как `site.test.ts` держит «страница = приложение»; за это проект уже
  платил (тексты расходятся, когда их держит только память).

## Что делаем
1. `docs/store-listing.md` — структура по Д2 с заголовками-маркерами; тексты ru первыми (канон),
   en — вторым каноном, es/pt — черновиками с пометкой «нейтив не вычитал» (как статус `draft`).
2. Тест лимитов (Д5) + красный прогон.
3. `docs/release-checklist.md`: пункты «Название», «Описания на 4 языках», «Ключевые слова» → `[~]`
   со ссылкой на файл («черновики есть, вычитка редактором/нейтивом — волна Cowork»).
4. Промт Cowork на вычитку es/pt — дописать в существующий план волны вычитки 54
   (`docs/prompts/28n-native-review.md` — проверить, что это та самая волна; если нет — новый
   `docs/prompts/57-store-native.md`).
5. Документы: backlog, changelog, CLAUDE.md статус.

## Что НЕ делаем
- Скриншоты сторов, иконку, промо-видео — этап EAS/девайс.
- Не заводим аккаунты и не заполняем формы.
- Не пишем тексты подписки/цены (53б: строку цены отдаёт магазин; в описании — «подписка Premium
  открывает…» без чисел).
