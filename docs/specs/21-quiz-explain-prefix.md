# Спека 21 (код-часть) — префикс «Верно / Не совсем» перед пояснением викторины

Статус: реализация без отдельного согласования (мелкая задача <30 строк, решение по формату
принято редактором 13.08 — вариант (б) из backlog).

## Цель

Пояснение `explain` показывается после ЛЮБОГО ответа, но 31 текст из 50 написан под верный ответ
и начинается с «Верно!/Да!» — на неверном ответе приложение поздравляет за ошибку. Код добавляет
нейтрализующий префикс от себя: пользователь сначала видит вердикт, потом пояснение.

## Что делаем

- Перед текстом пояснения — префикс из i18n:
  - верный ответ: **«Верно.»** / en **“Correct.”** — цвет `success`;
  - неверный: **«Не совсем.»** / en **“Not quite.”** — цвет `danger`.
- Префикс — вложенный `Txt` в том же абзаце пояснения (тот же шрифт `fonts.display` 15/22,
  `fontWeight: '600'`), после него пробел, дальше текст `explain` обычным цветом `text`.
- Появляется вместе с пояснением сразу по ответу (не ждёт подсветки верного варианта через 400мс).

## Что НЕ делаем

- Тексты `explain` не трогаем — зачины из 31 текста убирает редактор (контентная половина
  задачи 21). До её правки допустимо временное «Не совсем. Да! …» — решение 13.08.
- Отдельного блока/плашки под вердикт не рисуем: в макете пояснения нет вовсе
  (дорисовка (л) в задаче 15), вводить новую сущность не с чего.
- Плюрализации и переменных в ключах нет.

## Значения

- Цвета ТОЛЬКО токенами: `t.success` / `t.danger` — те же, которыми уже подсвечены верный
  и неверный варианты ответа на этом экране (design-system: состояния викторины).
- Типографика префикса = типографике пояснения (`st.explain`), меняется только цвет и вес.

## План

1. `src/lib/i18n.ts` — ключи `lesson.explainRight` / `lesson.explainWrong` в ru и en.
2. `app/lesson/[id].tsx` — в блоке `{answered && …}` вложенный `Txt` с префиксом по
   `picked === step.question.correct`.
3. `npx tsc --noEmit`, `npm test` (новых формул нет — новых тестов не требуется,
   контракт-тесты контента не задеваются).

## Готово, когда

- [ ] Верный ответ → пояснение начинается с золотисто-зелёного «Верно.» (цвет `success`).
- [ ] Неверный ответ → «Не совсем.» цветом `danger`, появляется сразу, ещё до подсветки
      верного варианта.
- [ ] Работает в обеих локалях (ru/en) и обеих темах (цвета токенами).
- [ ] `npx tsc --noEmit` чистый, `npm test` зелёный.
- [ ] Веб-проверка 6б: пройти вопрос верно и неверно, консоль без ошибок.
