# Спека 25: перевёрнутые приписки для сфер

Статус: на согласовании у Артёма (15.08). Формат решён Артёмом 15.08 — **вариант (б)**:
короткая перевёрнутая приписка 1–2 предложения внутри каждой вкладки-сферы, общий блок
«Перевёрнутая» остаётся как есть.
Решения брейншторма 15.08 (выбраны Артёмом из вариантов):
- вид приписки — в том же блоке сферы, после основного текста: разделитель + мини-заголовок
  «ПЕРЕВЁРНУТАЯ» + текст приглушённым;
- пока приписка не написана (статус `todo`) — не показывается ВООБЩЕ (ни разделителя,
  ни заголовка): черновики появляются порциями, и плейсхолдер «Текст готовится» шумел бы
  в 4 вкладках × 78 карт сразу. Правило «Текст готовится» остаётся за основными блоками.

## Цель

Замечание редактора (13.08, editor-questions.md): у карты один блок «Перевёрнутая» на все
сферы — под вкладкой «Любовь» он выглядит сферным текстом, но им не является. Даём каждой
сфере свой короткий перевёрнутый смысл, не раздувая корпус (полный формат (а) удваивал бы
объём и затем умножался на ES/PT — задача 28).

## Что делаем

### 1. Схема контента — 4 новых блока

У каждой из 78 карт в `content` появляются блоки той же формы `{ru, en, status}`:

- `love_reversed`, `career_reversed`, `finances_reversed`, `health_reversed`

Стартовый статус `todo`, пустые `ru`/`en`. Блоков у карты становится 12 (у 22 старших — 13
с `birth_path`). Тип `TarotCard` НЕ меняется: `content` уже `Record<string, CardContentBlock>`.

Отклонённые альтернативы: вложенное поле `reversed` внутри существующих блоков сфер — делит
один статус с основным текстом (вычитку приписки отдельно не записать — та же боль, что «один
статус на два языка») и ломает единообразие, на котором держатся все скрипты; отдельный объект
с 4 под-текстами — то же самое.

### 2. Конвейер

- `scripts/build_cards.py`: `BLOCKS` += 4 новых ключа; при переносе контента из существующего
  файла ДОЛИВАТЬ карте недостающие ключи из `BLOCKS` пустыми todo-блоками — скрипт сам чинит
  схему при будущих пересборках.
- Разовое добавление пустых блоков в `content/cards.json` — короткий python-прогон в коммите 1
  (в репо не сохраняется; повторяемость гарантирует контракт-тест).
- `scripts/content_stats.py`, `scripts/set_status.py` — БЕЗ правок: перебирают блоки карты
  обобщённо, знаменатель «готово N/12» посчитается сам.

### 3. UI страницы карты (`app/card/[id].tsx`)

Для активной сферы, КРОМЕ `general`: читаем `blockOf('<сфера>_reversed')`; `todo` → ничего
не рендерим (blockOf уже отдаёт `todo: true` и для отсутствующего блока — старые данные
не роняют страницу). Иначе — внутри того же `Block` сферы, через `children`, после основного
текста:

- разделитель: высота 1, цвет `line`, marginTop 12;
- заголовок: существующий ключ `card.reversed`, UPPERCASE, Overline 9 / letterSpacing 2.5
  (как заголовок Block), цвет `muted` (приглушённый — не спорит с акцентным заголовком
  панели), marginTop 10;
- текст: Cormorant 15/22 (размер из типовой шкалы design-system — тот же, что у пояснений
  викторины), цвет `muted`, marginTop 6.

`children` в `Block` рендерятся внутри `Animated.View` с `contentStyle` — приписка гаснет
и проявляется вместе с текстом сферы (fade 130/350) без дополнительного кода.

Общий блок «Перевёрнутая» под вкладками не меняется. Новых i18n-ключей нет.

Макет design-reference.html этот элемент не покрывает (решение 15.08 новее макета) —
расхождение осознанное, дорисовка уходит пунктом в задачу «Макет: правки дорисовок 14.08».

### 4. Контент — 624 приписки, 5 заходов

4 сферы × 78 карт × 2 языка. Порциями по образцу задачи 26, каждый заход — свой цикл
черновики → вычитка редактора → `set_status.py reviewed`:

1. Старшие арканы (22 карты, 176 текстов)
2. Жезлы (14 карт, 112)
3. Кубки (14, 112)
4. Мечи (14, 112)
5. Пентакли (14, 112)

Правила текста:
- 1–2 предложения, ориентир ru ~100–220 знаков; en — не подстрочник (глоссарий content-guide).
- Тон — content-guide: перевёрнутая = приглушённая/искажённая/задержанная энергия карты
  в этой сфере, НЕ «плохое предсказание»; «сбылось» и обещания сбычи запрещены; трудные
  карты — бережно (честно назвать + опора).
- Согласованность: не противоречить основному тексту сферы, общему блоку `reversed`
  и поисковым словам `search` (там уже лежат перевёрнутые смыслы — спека 04г); НЕ пересказывать
  общий блок «Перевёрнутая», а конкретизировать под сферу.
- Статус один на оба языка (известное ограничение схемы — задача «Подготовка к многоязычию»);
  объём будущей вычитки EN растёт вместе с корпусом.

### 5. Тесты

Новый контракт-сьют `src/lib/__tests__/cardsContent.test.ts`:
- у всех 78 карт есть все 4 новых блока;
- статус каждого — валидный `BlockStatus`;
- блок со статусом не-`todo` непуст в ОБОИХ языках;
- у todo-блока оба языка пустые (черновик без смены статуса — ошибка конвейера).

## Что НЕ делаем

- Не трогаем общий блок `reversed`, остальные 8–9 блоков, `keywords`/`search`.
- Не меняем тип `TarotCard`, схему стора (persist остаётся 7 — правило «следующая задача,
  меняющая схему СТОРА, поднимает до 8» этой задачи не касается: здесь схема контента).
- Не показываем приписку на вкладке «Общее» и не добавляем плейсхолдеров.
- Перевёрнутые тексты для `day_card`/`symbolism`/`birth_path` — не существуют как понятие.
- ES/PT — задача 28, после вычитки канона.
