# Спека 46 — коллекция-альбом: изученные карты открываются в альбоме (этап 4 плана)

Статус: спека написана 19.08 (брейншторм: вопросы 5–7 бэклога решены по рекомендациям Claude
решением Артёма 19.08, остальные развилки — ниже в таблице «Решения»), ждёт «ок» Артёма.
Реализация — сессия на Opus 5 по детальному плану `docs/plans/46-collection.md` (код по шагам
отдаётся sonnet-сабагентам), ветка `feat/46-collection`, веб-проверка 6а/6б и лайв-проверка
Артёма на iPhone — как у любой UI-задачи.

Контекст: п. 13 master-plan §3.1-Р («Коллекция-альбом — изученные карты открываются в альбоме,
прогресс 23/78, уровни мастерства каждой карты. Крючок „закрыть коллекцию“»), этап 4 плана,
вторая задача этапа после флеш-карт (45). Макет — `v-collection` в `design-reference.html`
(Cowork, 15.08), нарисован «простейшим вариантом»: экран с прогрессом, сеткой старших арканов
и четырьмя строками мастей. Вход с экрана «Карты» в макете НЕ нарисован (к экрану ведёт только
демобар; кнопка «назад» подписана «КАРТЫ») — вход определяется здесь и дорисовывается в макет
(правило 6а-0).

## Решения

| Вопрос | Решение |
|---|---|
| 5 · Вход | **Отдельный экран `app/collection.tsx`, вход со вкладки «Карты»** — строка-панель «Коллекция · N ИЗ 78 ›» под заголовком «78 карт», над поиском. Режим-переключатель внутри справочника отклонён: справочник — инструмент поиска (фильтры, скролл-панель), альбом — витрина прогресса, у них разные задачи и разные состояния. Нарисованная в макете кнопка «назад → КАРТЫ» совпадает с решением. |
| 6 · Что открывает карту | **Пройденный урок** — `learnedCardIds(course, lessonsProgress)`, то же множество, что бейдж «ИЗУЧЕНО ✓» справочника и колода тренажёра (45): «открыто в альбоме» = «изучено» = «в колоде повторения», три места читают одно правило. «Первое повторение в тренажёре» отклонено: тренажёр повторяет уже изученное, встреча с картой в нём не первая. |
| 7 · Масти до старта | **Компакт-строками «0 ИЗ 14»**, как нарисовано. Общее правило секции (см. ниже): секция без единой открытой карты — строка; с хотя бы одной — сетка с заголовком «НАЗВАНИЕ · N ИЗ M». Применяется и к старшим арканам: у новичка без уроков альбом = прогресс «0 из 78» + подсказка + пять строк. Альбом «растёт на месте» по мере курса: после М2 — ровно состояние макета (8 из 78, старшие сеткой, масти строками), после m4l1 — «ЖЕЗЛЫ · 5 ИЗ 14» сеткой, остальные масти строками. |
| Глифы мастей 🜂🜄🜁🜃 из макета | **Не используем** — вместо них слева в строке масти мини-рубашка 22×36 (`StarBack`: градиент рубашки + ✶, тот же плейсхолдер, что у закрытой ячейки сетки, уменьшенный). Причина: алхимические символы (блок U+1F700) — глифы системного шрифта, на iOS их наличие не гарантировано (на Windows-браузере макета они есть из Segoe UI Symbol); правило задачи 16 — «символ в макете указывает на смысл, а не на способ рисования». Мини-рубашка заодно говорит ровно то, что нужно: «14 закрытых карт». ⚠️ Если Артём на ревью спеки проверит, что 🜂🜄🜁🜃 видны на его iPhone (в Заметках), решение можно откатить к глифам — тогда строка получает текстовый глиф 17 `accent` вместо мини-рубашки; в остальном спека не меняется. |
| Уровни мастерства карты (master-plan п. 13) | **Не в этой задаче.** Макет их не рисует (правило бэклога: без эталона UI не делаем), в коде понятия нет. Данные для них уже есть (`srs[cardId].intervalDays`), вывод — чистая функция; заводится хвостом 46 в бэклоге: сначала дорисовка в макет, потом спека. |
| Ячейка сетки | **Вынос** локальной `Cell` из `app/(tabs)/cards.tsx` в общий `CardCell` (второе место + новый режим «закрыто») — по правилу «2+ раза». |
| Рубашка со звездой ✶ | **Вынос** связки `CardBackSurface + ✶` в общий `StarBack`: она уже живёт копиями в `SpreadCard` и `SpreadRow`, коллекция стала бы третьей (правило «сначала выносы, потом новый код», прецедент 45б). |
| Строка «иконка + название + счётчик» | Новый общий `CountRow` (геометрия `.suitrow` макета): четыре строки мастей на экране альбома + строка-вход на «Картах» = пять мест одной разметки. `SettingsRow` не подходит: другая типографика (14/13 против 12.5/10 капс с трекингом) и радиус. |
| `filter: grayscale(.4)` закрытой ячейки | **Не воспроизводим**, только `opacity .42`. CSS-фильтры в RN на iOS поддержаны частично, а на двухцветной плашке (синий градиент + золотая ✶) при .42 прозрачности разница неразличима. Записывается в design-system как осознанное упрощение. |
| Хранение | **Ничего нового не храним**: альбом целиком выводится из `lessonsProgress`. Persist version остаётся 10, бэкап не меняется. |

## Цель

- У пользователя появляется «альбом», который заполняется по мере курса: открытые карты лежат
  картинками, закрытые — рубашками, масти до старта — строками «0 ИЗ 14». Крючок — «закрыть
  коллекцию» (78 из 78), видимый числом на «Картах» и полосой в альбоме.
- Один источник правды «изучено»: бейдж справочника, колода тренажёра и альбом читают
  `learnedCardIds`; никаких дубликатов множества.
- Логика чистая и под тестами; экран — тонкий слой, из общих компонентов.

## Что делаем

### А. Чистый модуль `src/lib/collection.ts` (под юнит-тестами)

- `type CollectionGroup = 'major' | 'wands' | 'cups' | 'swords' | 'pentacles'`;
  `COLLECTION_GROUPS` — порядок экрана: старшие, Жезлы, Кубки, Мечи, Пентакли (порядок чипов
  справочника и курса М4).
- `groupOf(card: TarotCard): CollectionGroup` — `arcana === 'major'` → `'major'`, иначе `suit`.
- `interface CollectionSection { group; cards: TarotCard[]; open: number; total: number }` —
  `cards` в порядке `number` по возрастанию (старшие 0–21, младшие 1–14: Туз … Король).
- `collectionSections(deck: readonly TarotCard[], learned: ReadonlySet<string>): CollectionSection[]`
  — пять секций в порядке `COLLECTION_GROUPS`, каждая карта колоды ровно в одной; `open` =
  число карт секции в `learned`, `total` = размер секции (22/14/14/14/14).
- `collectionProgress(sections): { open: number; total: number }` — сумма по секциям (8/78).
- `type SectionMode = 'grid' | 'row'`; `sectionMode(s) = s.open > 0 ? 'grid' : 'row'` — правило
  из таблицы решений, записано один раз.
- Тесты `src/lib/__tests__/collection.test.ts`: на реальной колоде — пять секций, тоталы 22+14×4 =
  78, каждая карта ровно в одной секции, порядок внутри секции по `number`; `open` считается
  по множеству (карта, которой нет в колоде, не считается); `collectionProgress` — сумма;
  `sectionMode` — 0 → row, 1 → grid; `groupOf` на карте каждой масти и на старшем аркане.

### Б. Общие компоненты (выносы — ДО нового кода)

- **`StarBack`** (`src/components/StarBack.tsx`) — `CardBackSurface` + ✶ (`Text` без `fontFamily`,
  правило Txt.tsx: ✶ нет в Manrope), звезда центрируется самим компонентом (absoluteFill-обёртка
  с центрированием), проп `starSize` (20 у `SpreadCard`, 13 у `SpreadRow`, 17 у закрытой ячейки
  сетки — `.gc .ph font-size:17px`, 9 у мини-рубашки строки). `SpreadCard` и `SpreadRow`
  переводятся на него; визуально — ноль изменений (проверяется скриншотом расклада до/после).
- **`CardCell`** (`src/components/CardCell.tsx`) — ячейка сетки карт из `cards.tsx` как есть
  (замер позиции на нажатии для перелёта, `Skeleton` до загрузки, подпись 9.5/600), плюс:
  `from: 'cards' | 'collection'` (параметр маршрута страницы карты → подпись «назад»),
  `badge?: string` (текст углового бейджа — справочник передаёт «ИЗУЧЕНО ✓» у изученных,
  альбом не передаёт ничего: в нём всё открытое изучено по определению), `closed?: boolean` —
  закрытая ячейка: вместо картинки `StarBack` при opacity .42 обёртки, подпись «· · ·»
  (литерал, типографика, не i18n) цветом `muted` при opacity .5, БЕЗ `PressableScale` и без
  onPress (карта скрыта — вести некуда; пружина обещала бы переход, прецедент `ReviewPanel`).
  Константы сетки `GRID_COLS = 3`, `GRID_GAP = 11`, `CELL_W` переезжают сюда и импортируются
  обоими экранами.
- **`CountRow`** (`src/components/CountRow.tsx`) — строка `.suitrow` макета: панель `panel`,
  бордер `line`, radius 13, паддинг 11/14, зазор 12; слева `icon` (Ionicons 17 `accent`) ЛИБО,
  если иконки нет, мини-`StarBack` 22×36 (radius 4, бордер `line`); название 12.5/600 `text`
  (`flex: 1`); справа счётчик «N ИЗ M» 10/700 ls1 `muted`; опционально `chevron`
  (`chevron-forward` 14 `muted`) и `onPress` → `PressableScale`, без onPress — обычный `View`.
  Пропсы: `{ icon?, title, count, total, chevron?, onPress? }`; текст счётчика — ключ
  `collection.ofTotal` («{{open}} ИЗ {{total}}»).

### В. Экраны

**Вход на «Картах»** (`app/(tabs)/cards.tsx`): внутри `FadeUp index={0}` шапки, под заголовком
«78 карт», с отступом 14 сверху — `CountRow icon="albums-outline" title=«Коллекция» count=open
total=78 chevron onPress → router.push('/collection')`. Показывается всегда, включая «0 ИЗ 78» —
ноль и есть крючок. `open` считается `collectionProgress(collectionSections(cards, learned))`,
`learned` у экрана уже есть (бейджи). Поиск и чипы ниже не меняются; scroll-aware панель не
затрагивается (строка живёт в потоке шапки и уезжает со скроллом).

**Экран альбома `app/collection.tsx`** — корневой стек ПОД ГАРДОМ онбординга (`_layout.tsx`,
урок 09), прозрачная нативная шапка с подписью «Карты» на кнопке назад (`headerBackTitle:
tr('tabs.cards')`), `useBackHaptic`, паддинг `insets.top + 64 + spacing.l` (как у тренажёра).
Список — `FlatList` с типизированными элементами (виртуализация: до 78 миниатюр), данные —
из `collectionSections`:
- шапка (`FadeUp 0`): Overline «КОЛЛЕКЦИЯ» 9.5/ls3.5 `muted` + «Альбом» Cormorant 28 `head` (`.date`/`.h2`);
- панель прогресса `.colprog` (`FadeUp 1`): `panel`, бордер `line`, radius 15, паддинг 12/15,
  отступ 14 сверху; строка «Открыто N из 78» Cormorant 600 16 `head`; под ней `ProgressBar`
  6px radius 3 с отступом 8 — заливка `open/total`, анимируется от 0 при входе (задержка 400,
  ход 1400, `PROGRESS_EASE`, `ReduceMotion.System` — тайминг `LevelCard`);
- подсказка (только при `open === 0`, в том же `FadeUp 1`): «Карты открываются по мере
  прохождения уроков курса» 12.5 `muted` по центру, maxWidth 270, отступ 18 сверху. Не
  `EmptyState`: экран не пуст — структура альбома (пять строк) видна, мини-рубашка ✦ рядом
  с пятью мини-рубашками ✶ строк дала бы два плейсхолдера на одном экране;
- секции в порядке `COLLECTION_GROUPS`, режим по `sectionMode`:
  - **сетка**: заголовок «СТАРШИЕ АРКАНЫ · 8 ИЗ 22» / «ЖЕЗЛЫ · 5 ИЗ 14» (`.date` влево:
    9.5/ls3.5 `muted`, капс; название — `collection.major` для старших, `cards.<suit>` для
    мастей, оба через `toUpperCase()` (прецедент `SpreadRow`); счётчик — `collection.ofTotal`),
    отступ 18 сверху;
    ряды по 3 `CardCell` (зазор 11 в обе стороны, отступ 10 от заголовка), открытые —
    картинка + название, `from="collection"`; закрытые — `closed`;
  - **строка**: `CountRow` без иконки (мини-рубашка), название как есть (`collection.major`
    «Старшие арканы» / `cards.<suit>` «Жезлы»), счётчик «0 ИЗ 14», без chevron и без onPress;
    зазор между строками 8, отступ 16 от предыдущей сетки (`.fadeup d5 margin-top:16`).
  Каскад: первые 6 элементов списка после панели — `FadeUp 2` (строки мастей — `FadeUp 3`),
  дальше без анимации (правило тела списков, задача 17).
- Тап по открытой ячейке → `/card/<id>?from=collection`, страница карты подписывает «назад»
  «Коллекция» (`BACK_TITLES.collection → card.backCollection`). Закрытая ячейка и строка масти
  не реагируют.
- Хаптика: у навигации нет (как у ячеек справочника и `ReviewPanel`), `useBackHaptic` на возврате.

**Маршрут**: `<Stack.Screen name="collection" options={transparentHeader(t)} />` внутри
`Stack.Protected guard={onboarded}` в `app/_layout.tsx` — прямой `/collection` до онбординга
редиректит на онбординг (проверяется в 6б).

**i18n** (ru + en, `src/lib/i18n.ts`): `cards.collection` «Коллекция»/«Collection»;
`card.backCollection` «Коллекция»/«Collection»; новое пространство `collection`: `overline`
«КОЛЛЕКЦИЯ»/«COLLECTION», `title` «Альбом»/«Album», `opened` «Открыто {{open}} из {{total}}»/
«Collected {{open}} of {{total}}», `ofTotal` «{{open}} ИЗ {{total}}»/«{{open}} OF {{total}}»,
`major` «Старшие арканы»/«Major arcana» (в заголовке секции — через `toUpperCase()`), `hint`
«Карты открываются по мере прохождения уроков курса»/«Cards open as you complete course lessons».
Числительных с согласованием нет («из 78», «ИЗ 14» — число без склоняемого слова), плюрализация
не нужна.

## Что НЕ делаем (осознанно)

- Уровни мастерства карты, ачивки, празднование «78 из 78», шаринг альбома — нет макета, YAGNI.
- Открытие карты чем-либо кроме пройденного урока (карта дня, тренажёр, расклад) — решение 6.
- Тап по закрытой ячейке / строке масти — ничего (ни подсказки, ни покачивания: карта скрыта
  намеренно, переход невозможен).
- Фильтры, поиск, сортировка в альбоме — это справочник.
- Новых полей стора, бэкапа, миграций — нет (альбом выводится).
- Коллекция в профиле (стата «Открыто N») — не добавляем; третья стата-коробка «ЗАМОРОЗКА»
  уже заняла ряд из трёх.

1. «Карты»: под «78 карт» строка «Коллекция · N ИЗ 78 ›». Тап → альбом, «назад» подписан «Карты».
2. DEV-сброс прогресса курса → альбом: «Открыто 0 из 78», подсказка, пять строк со
   мини-рубашками; шрифты, паддинги, обе темы.
3. Пройти (или DEV-завершить) уроки m2l1–m2l4 → альбом: «8 из 78», полоса заполняется плавно
   при входе, сетка старших: 8 картинок + 14 рубашек «· · ·»; тап по открытой → страница карты
   («назад · Коллекция»), тап по закрытой — ничего.
4. Завершить m4l1 → «ЖЕЗЛЫ · 5 ИЗ 14» сеткой между старшими и строками остальных мастей.
5. Расклады: разложить «Три карты» — рубашки карт и мини-карты в дневнике выглядят как раньше.
6. Хаптика на возврате из альбома (Light), свайп «назад» работает.
