# 04 · Справочник карт = эталон

Статус: утверждена Артёмом 10.08, в реализации · экран `app/(tabs)/cards.tsx`

## Цель

Довести таб «Карты» до эталона: карту можно найти по названию или по смыслу, фильтры не разъезжаются
на две строки, а поиск остаётся под рукой на любой глубине списка (78 карт = 26 рядов сетки).

## Решения, принятые до начала (10.08)

1. **Липкая панель (вариант B).** Поиск и чипы едут вместе с содержимым, но прилипают к верху при
   скролле — на blur-подложке `navBg`, как таб-бар. Зафиксировано в `design-reference.html`
   (`.stickysearch`) и в product-spec §3.
2. **Без счётчиков в чипах** — прав макет; product-spec §3 поправлен.
3. **Бейдж «Изучено ✓» — не в этой задаче.** Он ставится по пройденным урокам, а движка уроков нет
   (задача 08). Переносится туда целиком, вместе с полем прогресса в сторе.
4. **Поиск ищет по названию И по ключевым словам** текущего языка (`keywords` в `cards.json`):
   новичок чаще помнит смысл («любовь»), чем имя. Формулировку в product-spec §3 обновить.
5. **Поиск всегда по всей колоде**: первый введённый символ сбрасывает чип на «Все». Иначе
   «Мечи» + «шут» дают пустой экран, и причина неочевидна.

## Что делаем

### 1. Липкая панель «поиск + чипы»

Композиция экрана сверху вниз: overline «СПРАВОЧНИК · РАЙДЕР–УЭЙТ 1909» → заголовок «78 карт»
(оба скроллятся и уезжают) → **липкая панель** (поиск + чипы) → сетка 3 колонки.

Панель: фон `navBg` + размытие, растянута на всю ширину экрана (в макете `margin:0 -18px` —
выход за поля контента), внутренние отступы 18 по бокам, 14 сверху, 10 снизу, снизу граница 1px `line`.
Размытие делаем как в таб-баре: `BlurView` + слой `navBg` поверх (`app/(tabs)/_layout.tsx`) — эта пара
теперь встречается дважды, поэтому выносится в общий компонент `BlurSurface`.

Реализация: `SectionList` с одной секцией — `ListHeaderComponent` = overline + заголовок (скроллится),
`renderSectionHeader` = панель (прилипает), `stickySectionHeadersEnabled` включаем явно, чтобы работало
и на Android (по умолчанию RN включает липкость только на iOS). Сетку 3 колонки делаем рядами:
`SectionList` не умеет `numColumns`, поэтому данные — массив рядов по 3 карты, элемент списка = ряд.

Известное отличие от макета: в CSS панель прилипает с `top:-16px`, то есть первые 16px её верхнего
поля успевают уехать под статус-бар. В RN липкая секция прилипает вплотную к верху области контента;
отличие — 16px в момент прилипания, повторять его не будем.

### 2. Поиск

Поле — `TextInput` внутри панели: плейсхолдер «Найти карту…» / «Find a card…», иконка-лупа
`search-outline` слева, крестик очистки `close-circle` справа (появляется, когда есть текст).
Ввод фильтрует мгновенно, без задержки: 78 карт фильтруются за доли миллисекунды, дебаунс не нужен.

Правила сопоставления (чистая функция, см. §5):
- регистр не важен; «ё» приравнивается к «е» (иначе «жрец» не найдёт «Иерофанта», а «еж» — «ежа»);
- пробелы по краям срезаются, пустой запрос = нет фильтра;
- совпадение — подстрокой, по названию карты и по любому её ключевому слову текущего языка;
- первый символ в пустом поле сбрасывает активный чип на «Все».

Пустой результат: по центру, вместо сетки — «Такой карты нет — проверьте написание» /
«No such card — check the spelling» (product-spec §3), цвет `muted`, шрифт 12.5.

Клавиатура: `keyboardDismissMode="on-drag"` (прячется при скролле сетки),
`keyboardShouldPersistTaps="handled"` (тап по карте срабатывает с первого раза, а не сначала
закрывает клавиатуру), `returnKeyType="search"`, автокоррекция и автокапитализация выключены.

### 3. Чипы-фильтров

Одна строка с горизонтальной прокруткой, без видимой полосы прокрутки (`.seg`: `overflow-x:auto`,
`scrollbar-width:none`), отступ от поиска 9, между чипами 6. Активный — фон `chipBg`, бордер `frame`,
текст `accent`; остальные — бордер `line`, текст `muted`. Хаптика на тапе уже есть.
Подпись «Старшие арканы» укорачивается до «Старшие» / «Major» — ключ `cards.major` используется
только здесь (на странице карты подпись аркана — отдельная строка, `app/card/[id].tsx:153`).

### 5. Логика поиска — отдельный модуль с тестами

`src/lib/cardSearch.ts` (чистые функции, без React):
- `normalize(s: string): string` — нижний регистр, «ё»→«е», обрезка пробелов;
- `matchesQuery(card, query, lang): boolean` — совпадение по названию или ключевому слову;
- `filterCards(cards, { query, filter, lang }): TarotCard[]` — фильтр по аркану/масти + поиск;
- `toRows<T>(items: T[], size: number): T[][]` — нарезка на ряды для сетки.

Юнит-тесты `src/lib/__tests__/cardSearch.test.ts` (правило проекта: новый алгоритм — тест в том же
коммите): совпадение по имени; по ключевому слову; регистронезависимость; «ё/е» в обе стороны;
пустой запрос возвращает всё; несуществующий запрос — пустой массив; фильтр по масти без запроса;
`toRows` при 78 картах даёт 26 рядов, последний ряд неполный при 77.

### 6. Что НЕ делаем

- Бейдж «Изучено ✓» — переезжает в задачу 08 (нет данных о пройденных уроках).
- Скелетоны — уже реализованы (`Skeleton` поверх миниатюры до загрузки), доделывать нечего.
- Сортировки, избранное, счётчики в чипах, поиск по английским именам в русском интерфейсе.
- Перелёт миниатюры на страницу карты — работает с задачи 03, не трогаем.

## Точные значения (из `design-reference.html`)

**Липкая панель** `.stickysearch`: паддинги 14 / 18 / 10 / 18, фон `navBg`
(тёмная `rgba(7,9,23,.66)`, светлая `rgba(252,248,238,.7)`), размытие 14px CSS →

зазор 6, отступ сверху 9. Активный: фон `chipBg`, бордер `frame`, текст `accent`.

**Сетка** `.grid`: 3 колонки, шаг 11, отступ сверху 15. Миниатюра: радиус 11, бордер 1px `line`,

**Появление** (`fadeup`): overline+заголовок — d1, панель — d2, сетка — d4 (компонент `FadeUp`).

## Отчёт о проверке (веб, 10.08)

**6а — сверка с макетом.** Скриншоты 390×844 в `docs/screenshots/04/`: приложение —
`04-cards-{dark,light}-{top,sticky}.png`, макет — `04-mockup-cards-{top,sticky}.png`.
Совпало: заголовок, overline, панель поиска, чипы в одну строку, сетка 3×11, подписи,
поведение прилипания (содержимое уезжает под размытую панель).

Осознанные отличия от макета:
1. **Панель во всю ширину.** В CSS у неё `margin:0 -18px` при поле экрана 22 — остаётся 4px
   градиента по бокам. Сделано во всю ширину, как таб-бар: полоска фона по краям липкой панели
   на устройстве читалась бы как дефект вёрстки.
2. **Прилипает вплотную к верху.** В макете `top:-16px` — первые 16px панели уезжают, и над ней
   видны верхушки карт. В RN липкая секция останавливается на границе области контента.
3. **Бейджа «ИЗУЧЕНО ✓» нет** — перенесён в задачу 08 (решение 10.08, данных о пройденных уроках нет).

**6б — прокликивание.** Чип «Жезлы» → 14 карт, чип подсвечен золотым. Ввод «наставник» → Иерофант
(поиск по ключевому слову), «влюбленные» без «ё» → Влюблённые, «любовь» → пустое состояние с текстом
из спеки, крестик → снова 78 карт, ввод при активном чипе сбрасывает его на «Все». Тап по карте →
`/card/hierophant?from=cards`. Консоль после чистой загрузки: 0 ошибок; из предупреждений — только
известное `props.pointerEvents is deprecated` из библиотеки (было до задачи).

**Найдено попутно (контент, не код):** ни у одной карты в `keywords` нет слов «любовь», «деньги»,
«работа» — всего 85 уникальных ключевых слов на 78 карт. Поиск по смыслу будет находить мало,
пока редактор не расширит списки. Занесено в backlog отдельной задачей для жены.
