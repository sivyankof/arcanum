# Спека 02 · Кнопка сброса карты дня (dev)

Статус: реализовано · Значения: docs/design-system.md

⚠️ Спека написана **задним числом**: кнопка появилась вместе с ранними работами по экрану «Сегодня»,
до появления обязательного процесса. Здесь зафиксировано, что сделано и какие решения приняты.

## Цель

Тестировать переворот карты дня, салют серии и хаптику многократно, не ожидая следующего дня.

## Что сделали

1. **`resetToday()` в `src/store/useApp.ts`** — отменяет сегодняшнюю карту: удаляет запись за сегодня
   из history, `lastDrawDate` откатывается на дату предыдущей записи (или null), серия −1 (не ниже 0).
2. **Строка в профиле** — «Сбросить карту дня» (иконка refresh, значение «DEV»), видна только
   при `__DEV__`. Экран «Сегодня» возвращает рубашку сам: эффект следит за `todayDraw()` и
   сбрасывает flip без перезахода.

## Принятые решения (отличия от формулировки в backlog)

- **`__DEV__` вместо пометки TODO-RELEASE**: код автоматически вырезается из релизной сборки,
  забыть убрать невозможно — надёжнее комментария. В Expo Go кнопка видна всегда (это dev-режим).
- **Раздел «Для разработки» не заводили**: строка одна, заголовок секции ради неё — шум.

## Ограничение (осознанное)

Точное прежнее значение серии не хранится: если сегодняшний draw сбросил серию после пропуска
(была 12 → стала 1), сброс вернёт 0, а не 12. Для dev-инструмента приемлемо, отмечено в комментарии.

## Критерии приёмки

- [x] Сброс возвращает рубашку сразу, без перезахода на таб.
- [x] Повторный draw снова переворачивает карту; при росте серии — салют у огонька.
- [ ] Прокликано в общей проверке 6б (вместе с остатком спеки 01).
- [x] В релизной сборке строки нет (`__DEV__`).
