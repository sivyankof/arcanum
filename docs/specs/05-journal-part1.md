# Спека 05 · Дневник, часть 1 — заметка к карте дня и история

Статус: ЗАКРЫТА 11.08.2026 — веб-проверка 6а/6б и лайв-проверка Артёма на iPhone пройдены ✓ · Эталон: `docs/design-reference.html` (вкладки «Профиль»,
«Сегодня») · Значения: `docs/design-system.md` §5 · Поведение: `docs/product-spec.md` §1, §5 ·
Данные: `docs/logic-spec.md` §3, §7

## Цель

Ежедневная петля перестаёт быть «открыл карту — забыл»: к карте дня можно записать мысль, а прошлые
дни собираются в дневник, к которому есть смысл возвращаться. Дневник строится сразу в финальной
структуре (месяцы), чтобы задача 06 доложила в него рефлексию, ничего не переписывая.

## Решения брейншторма (11.08)

1. **Объём — каркас по product-spec §5**, а не плоский список из формулировки backlog: навигатор
   по месяцам, карточка месяца, список записей, пустые состояния. Фильтр-чипы ✓/≈/✗ и полоска
   распределения ждут задачу 06 — без `outcome` их нечем наполнить.
2. **Ввод заметки — плашка на «Сегодня» + отдельный экран-модалка.** Инлайн-ввод в потоке (как
   в макете) на устройстве упирается в клавиатуру посреди длинного скролла, а редактировать заметку
   надо ещё и из дневника — то есть поле нужно в двух местах. Один экран обслуживает три входа:
   «Сегодня», дневник и будущую рефлексию (06).
3. **Дневник живёт в профиле** (как в макете), а «Тема · Язык · DEV-сброс» уезжают на отдельный
   экран за шестерёнку — этого требует product-spec §5, и без переезда список записей перемешался бы
   с переключателями.
4. **Шапку профиля к макету НЕ приводим**: имя и аркан рождения — задача 09, уровень/XP — 08,
   заморозка — 10. Заводим отдельную задачу «профиль = эталон» в backlog.
5. **Править можно только сегодняшнюю заметку** (logic-spec §3: ответ фиксируется в полночь).

## Что делаем

### 1. Данные и стор

Схема хранения НЕ меняется: `note?: string` уже есть в `DailyDraw`, `version` persist остаётся `1`,
миграция не нужна.

Тип `DailyDraw` переезжает из `src/store/useApp.ts` в `src/lib/journal.ts` (стор импортирует его
оттуда и реэкспортирует) — чтобы чистые функции дневника не зависели от стора.

Новый экшен стора:

```ts
setNote: (date: string, text: string) => void
```

Пишет заметку в запись `history` за указанную дату. Условия: запись существует И `canEditNote(date)`
(дата = сегодня). Текст проходит `normalizeNote` (trim + обрезка до 500 символов, logic-spec §3);
пустой результат удаляет поле `note` из записи, а не пишет пустую строку.

### 2. Модуль `src/lib/journal.ts` — вся арифметика дневника

Чистые функции без React, покрыты юнит-тестами:

| Функция | Возвращает |
|---|---|
| `canEditNote(date, today?)` | `boolean` — правка разрешена только за сегодня |
| `normalizeNote(text)` | trim + обрезка до 500 |
| `monthsWithEntries(history)` | `['2026-08', '2026-07', …]` — только месяцы с записями, новые первыми |
| `entriesOfMonth(history, month)` | записи месяца, новые сверху |
| `monthSummary(history, month)` | `{ count, withNote, topCardId, topCount }` |
| `cardHistory(history, cardId)` | `{ times, lastDate, lastNote? }` |

Правила, которые легко потерять:

- **«Карта месяца»** — мода по `cardId` внутри календарного месяца. При равенстве частот выигрывает
  карта с самой свежей записью — выбор детерминированный, `Math.random` запрещён (logic-spec §9).
- **`lastNote`** — заметка из самой свежей записи, *у которой заметка есть*; не из самой свежей
  записи вообще (иначе вчерашняя карта без заметки прятала бы позавчерашнюю запись с текстом).
- Функции сами сортируют историю по дате: порядок в сторе не гарантирован (сброс карты дня,
  будущий импорт из задачи 11).

### 3. Экран «Сегодня» — плашка заметки

Появляется под панелью «Значение дня» **после открытия карты**, внутри того же анимированного
контейнера (`meanStyle`), поэтому проявляется вместе со значением. Компонент
`src/components/NotePlate.tsx` — по design-system §5 «Поле вопроса/заметки»:

- пусто: бордер **пунктирный** `line`, radius 13, паддинг 10×13, текст `muted` 11.5 —
  «+ Добавить заметку о дне…»;
- заполнено: бордер **сплошной** `line`, текст `text`, до 3 строк с обрезкой «…».

Тап (`PressableScale` + `hapticTap`) → `/note/<сегодняшняя дата>`. Пунктир = «можно написать»,
сплошной = «написано» — правило design-system.

### 4. Экран заметки — `app/note/[date].tsx`

Модальная презентация (`presentation: 'modal'`), регистрируется в `app/_layout.tsx`.

Состав сверху вниз: шапка стека с заголовком «Заметка» → строка даты (Overline, muted) → мини-карта
дня 44×72 с рамкой `frame` и название карты (Display M) → поле ввода → счётчик → CTA «Сохранить».

- Поле: `TextInput` multiline, `maxLength={500}`, `autoFocus`, minHeight 140, фон `panel`,
  бордер `line`, radius 13, паддинг 12×14, шрифт Cormorant 16/24 (design-system §5 «Инпут»),
  плейсхолдер «О чём этот день?» цветом muted.
- Счётчик «124 / 500» справа под полем: muted 10.5; от 450 — цвет `accent`.
- CTA «Сохранить» — золотой градиент, `hapticTap`, вызывает `setNote` и закрывает экран.
  (`hapticSuccess` бережём для настоящих вех — правило из экрана «Сегодня».)
- `KeyboardAvoidingView` (`behavior='padding'` на iOS) — клавиатура не перекрывает CTA.
- Уход с несохранёнными правками (кнопка «назад» или свайп вниз) → `Alert` «Уйти без сохранения?
  Заметка не сохранится» (Уйти / Остаться) через слушатель `beforeRemove` — тот же паттерн, что
  у раскладов в product-spec §4. Если текст не менялся — уход молча.
- Если запись за дату не сегодняшняя или отсутствует, экран открывается в режиме чтения:
  поле недоступно для правки, CTA скрыта (страховка от прямой ссылки).

### 5. Профиль — дневник

Профиль переезжает со `ScrollView` на `FlatList` (виртуализация до 31 записи месяца,
product-spec §5): `ListHeaderComponent` = заголовок + статы + навигатор + карточка месяца,
`data` = записи выбранного месяца, `ListEmptyComponent` = пустое состояние.

- **Шестерёнка** — круг 34px в правом верхнем углу (бордер `line`, фон `panel`, иконка
  `settings-outline` 17px `muted`) → `/settings`.
- **Навигатор месяца** (`.mnav`): marginTop 22, по краям — круглые стрелки 26×26, radius 13,
  бордер `line`, символ `accent` 12px; по центру «ДНЕВНИК · АВГУСТ 2026» (Overline 10px,
  letterSpacing 3, muted 700). Листаются **только месяцы с записями**; крайняя стрелка гаснет
  до opacity 0.35 и не нажимается. Выбранный месяц — локальное состояние экрана, при входе =
  самый свежий месяц с записями.
- **Карточка месяца** (`.mcard`): панель radius 15, паддинг 12×14, gap 12; мини-карта 38px
  (radius 5, бордер `frame`) + Overline «КАРТА МЕСЯЦА» (8.5px, ls 2, accent) + «Верховная Жрица ·
  4 раза» (Cormorant 600, 15, head) + строка «18 записей · 5 с заметкой» (muted 10.5).
  Показывается, только если в месяце есть записи. Строка «Отозвалось X из Y дней» и трёхсегментная
  полоска — задача 06.
- **Строка записи** (`.jrow`, design-system §5 «Строка дневника»): панель radius 13, паддинг 9×12,
  gap 11, marginTop 8; мини-карта 30px (radius 4, бордер `frame`) + дата Overline 9px/ls 1.5 muted
  + заметка 12px `text` одной строкой с обрезкой «…», без заметки — «Без заметки» цветом muted.
  Место под отметку ✓/≈/✗ справа занимает задача 06.
  - тап → `/card/<id>?from=journal` (подпись нативной кнопки «назад» — «Профиль»);
  - долгий тап по **сегодняшней** записи → `/note/<дата>` + `hapticTap`; по прошлым записям долгий
    тап ничего не делает.
- **Пустые состояния** (design-system §7 — мини-рубашка + тёплая фраза): нет записей вообще →
  рубашка 44×72 + «Первая запись появится после карты дня». Пустых месяцев в навигаторе не бывает,
  поэтому второго пустого состояния в этой задаче нет (оно придёт с фильтрами в 06).

### 6. Экран настроек — `app/settings.tsx`

Обычный стековый экран (заголовок «Настройки», назад → профиль). Переезжают как есть строки
`Row`: Тема · Язык · сброс карты дня под `__DEV__`. Компонент `Row` переезжает из `profile.tsx`
в `src/components/SettingsRow.tsx` — он нужен обоим экранам (профиль ещё получит строки в задачах
09–13, а дублировать запрещено).

### 7. Страница карты — «Ваша история с картой»

Блок `Block` с `accentBorder` (золотая рамка `frame`, как контекстный блок «ваша карта сегодня»),
заголовок «ВАША ИСТОРИЯ С КАРТОЙ», встаёт **после «Символики»** (product-spec §3). Показывается,
только если `cardHistory(...).times > 0`.

Текст: «Выпадала 4 раза · последняя 11 августа», и если есть заметка — со второй строки
««Решилась написать первой — и не зря»». Счётчик «отзывалась N» добавит задача 06.

### 8. Тексты (i18n, ru + en)

Новые ключи: `journal.*` (заголовок навигатора, «КАРТА МЕСЯЦА», «N раз», «18 записей · 5 с заметкой»,
«Без заметки», пустое состояние, «ВАША ИСТОРИЯ С КАРТОЙ», «Выпадала N раз · последняя {{date}}»),
`note.*` (заголовок экрана, плейсхолдер, счётчик, «Сохранить», текст подтверждения выхода,
подпись плашки «+ Добавить заметку о дне…»), `settings.title`, `card.backProfile`.
Числительные «раз/раза/раз» и «запись/записи/записей» — через плюрализацию i18next
(`_one/_few/_many` для ru, `_one/_other` для en). Тон — design-system §8: на «вы», тепло.

## Тест-кейсы (юниты, `journal.test.ts`)

- `monthsWithEntries`: пустая история → `[]`; записи июля и августа → `['2026-08','2026-07']`;
  три записи одного месяца → один элемент.
- `entriesOfMonth`: границы месяца (31.07 не попадает в '2026-08', 01.08 попадает); порядок —
  новые сверху даже при перемешанной истории.
- `monthSummary`: `count` и `withNote` считаются по месяцу; мода определяет `topCardId`;
  при равенстве частот выигрывает карта со свежайшей записью (детерминизм — 100 вызовов
  дают один результат).
- `cardHistory`: `times` = число выпадений; `lastNote` берётся из свежайшей записи *с заметкой*,
  а не из свежайшей записи; карта не выпадала → `times: 0`, `lastNote: undefined`.
- `canEditNote`: сегодня → `true`, вчера → `false`.
- `normalizeNote`: пробелы по краям срезаются; 600 символов → ровно 500; строка из пробелов → `''`.

## Отчёт о реализации (11.08.2026)

`npx tsc --noEmit` чистый, `npm test` — 6 сьютов / 89 тестов зелёные (journal: 17 новых,
dates: +2 на `parseISODate`). Скриншоты обеих тем — `docs/screenshots/05/`.

### Отклонения от спеки (все осознанные)

1. **Подтверждение выхода — свой `ConfirmDialog`, а не системный `Alert`.** В react-native-web
   `Alert.alert` — пустая заглушка (`class Alert { static alert() {} }`): на вебе диалог не
   появился бы вовсе, а экран, задержанный на `beforeRemove`, не закрылся бы никогда — то есть
   проверка 6б была бы невозможна в принципе. Свой диалог одинаково работает на всех платформах
   и держит стиль приложения; он же понадобится раскладам («Уйти без сохранения?», product-spec §4).
2. **Золотая CTA вынесена в `src/components/CtaButton.tsx`.** На экране заметки кнопка появилась
   во второй раз — по правилу «повторяется 2+ раза → на верхний уровень» экран «Сегодня»
   переведён на тот же компонент.
3. **`Block` научился содержимому** (`children`, `text` стал необязательным) — плашка заметки
   живёт внутри обычной панели с Overline-заголовком. В комментарии компонента это было заложено.
4. **`EmptyState`** — отдельный компонент вместо разметки внутри профиля: пустые состояния
   понадобятся фильтрам в 06. Полноразмерный `CardBack` для миниатюры не годится (эмблема 96px
   и слово ARCANUM в 44×72 не помещаются), рубашка нарисована в миниатюре.
5. **Карточка месяца скрывается, если карта месяца выпадала один раз.** «КАРТА МЕСЯЦА · 1 раз»
   обещает закономерность, которой нет: при одном выпадении это просто случайная карта из ленты.
6. **Блок истории при единственном выпадении** говорит «Выпадала 11 августа» вместо
   «Выпадала 1 раз · последняя 11 августа» — второе звучит как отчёт (design-system §8).
7. **`formatMonthTitle` приписывает год вручную**: `year: 'numeric'` в русской локали даёт
   «август 2026 г.», и хвост «г.» лез в Overline навигатора.
8. **В вебе снята системная обводка фокуса** у поля заметки (`outlineStyle: 'none'`) — на
   устройстве её нет, а рядом с макетом она читалась второй рамкой.
