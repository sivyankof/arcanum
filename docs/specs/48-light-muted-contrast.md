# 48 · Контраст светлой темы: `muted` + бейдж «ИЗУЧЕНО ✓»

Статус: **ЗАКРЫТА 21.08 решением Артёма («оставляем так»)** — принята как есть, без отдельной
лайв-проверки; код в main с 20.08 (коммит 55b290a), хвост про макет закрыт 20.08 (коммит
5815ef0). Заведена из хвоста (ж) задачи 46 и находки задачи 47.

## Проблема

Два накопившихся замера (оба программные, формула WCAG):

1. **`muted` светлой темы `#a29878` не проходит норму для текста.** Плоский расчёт на `bg`
   `#f5eeda` — **2.48:1** при норме 4.5:1; замер по пикселям скриншота календаря (задача 47,
   с учётом полупрозрачных панелей) — **1.84:1**. Страдают все места, где мелкий текст красится
   `muted`: Overline-подписи (дни недели лунного календаря, «ВАШ ПУТЬ», overline панелей),
   вторичные подписи. Задача 25 уже упиралась в это (2.88:1 у приписки) и решала точечно
   поднятием до `text`; вывод «свойство светлой темы целиком» подтверждён замером 47.
   На тёмной теме `muted` `#7e86ab` даёт **5.20:1** — тёмную не трогаем.

2. **Бейдж «ИЗУЧЕНО ✓» на светлой теме почти невидим.** Текст бейджа — `accent2`, на светлой
   теме это ТЁМНОЕ золото `#8a6a24`, а подложка бейджа — чёрный скрим `rgba(0,0,0,.4)` поверх
   арта: тёмное на тёмном, расчёт **1.35–1.46:1** (светлый/средний арт). На тёмной теме
   `accent2` — светлое золото `#f0d9a4`, тот же скрим даёт 2.7–5.3:1 и читается.
   Дефект класса «цвет на тёмном скриме не должен следовать теме»: скрим одинаково тёмный
   в обеих темах (родня `themeVariant` из 06б — подложка не знает про тему приложения).

## Решение

1. **`lightTheme.muted` → `#6f664b`** (вариант с запасом — `#665d43`, выбирает Артём):
   - `#6f664b`: 4.93:1 на `bg`, 5.38:1 на `bgTop` — минимальное потемнение, иерархия
     `muted` (4.9) < `text` (9.1) сохраняется отчётливой;
   - `#665d43`: 5.64:1 / 6.17:1 — паритет с ощущением тёмной темы (5.20).
   Один токен чинит все места разом — свип по экранам не нужен, экраны красятся токеном.
2. **Текст бейджа на скриме — фиксированное светлое золото `#f0d9a4` в обеих темах**:
   новая константа `gold.onScrim` в `theme.ts` (объект `gold` уже платформа тем-независимых
   цветов), `CornerBadge` (вариант `label`) переводится с `t.accent2` на неё. Вариант `icon`
   (ярлычок «увеличить») — тот же скрим, та же правка.
   Скрим `rgba(0,0,0,.4)` не трогаем — геометрия и фон бейджа из эталона.
3. **design-system.md**: новое значение `muted` светлой темы; правило «цвет на тёмном скриме
   не следует теме» — в §5 рядом с правилом полупрозрачных панелей.

## Что НЕ делаем (осознанно)

- **Тёмную тему** — 5.20:1, норма выполнена.
- **Золотые мелкие подписи (`accent`, 3.13:1 на светлой)** — «МОДУЛЬ N ИЗ 6» и родня.
  Это фирменное золото: его «слабость» на светлом фоне — свойство направления, а не дефект
  токена; перекраска в тёмное золото поменяла бы вид приложения. Открытый вопрос Артёму —
  если решит чинить, отдельной задачей (вариант: на светлой теме мелкие золотые подписи
  красить `accent2` `#8a6a24` — 4.35:1).
- **Макет design-reference.html** — НЕ правим в этой задаче: файл занят Cowork-сессией
  дорисовок (урок 42: у «файл не трогай» должна быть пара «а трогает его вот кто»).
  Хвост: после Cowork-сессии обновить в макете `--muted` светлой темы и цвет бейджа,
  записан в бэклог в постановке задачи. ЗАКРЫТ 20.08 после приёмки дорисовок
  (коммит 5815ef0): `--muted` → #6f664b, `.st2` → фиксированный #f0d9a4.

## Отчёт веб-проверки (20.08)

Решения Артёма: токен `#6f664b` (минимальное потемнение), золотые подписи не трогать.

**Метод.** Playwright 390×844, сид light/dark; на каждом из 5 экранов собраны ВСЕ видимые
текстовые узлы с computed-цветом `muted`, фон каждого сложен из стека полупрозрачных предков
поверх худшей из баз `bg`/`bgTop`/`bgBottom` (метод задачи 25). Проверка «узлы вообще найдены»
встроена (урок 47 про `every` на пустом массиве): счётчики 10/29/11/5/90 узлов по экранам.

**Красный прогон (правило проекта).** Токен временно возвращён на `#a29878`, скрипт нацелен
на старый цвет: все 145 узлов ниже нормы (min 2.48) на всех пяти экранах. Проверка честная.

**Зелёный прогон.** Светлая: min **4.93:1** на всех экранах, ниже 4.5 — ноль узлов.
Тёмная: min 4.86–5.20 — в точности старые значения `#7e86ab`, тема не менялась.

**Бейдж.** Кроп по точному тексту «ИЗУЧЕНО ✓» (⚠️ нестрогий `text=ИЗУЧЕНО` матчится на строку
панели «изучено N из 22» — первый замер попал в неё). Пиксельный замер кропа: светлая и тёмная
**идентичны** (текст L=0.645, подложка L=0.179, контраст 3.04:1 на арте Дурака) — на тёмной
бейдж и раньше был `#f0d9a4`, светлая теперь совпала с ним пиксель в пиксель. До правки
расчётный контраст светлой был 1.35–1.46:1.

**6б.** Тап по строке луны на «Сегодня» ведёт на `/moon` (обе темы), ошибок консоли ноль.
Скриншоты: `docs/screenshots/48/` (5 экранов × 2 темы + кропы бейджа).
