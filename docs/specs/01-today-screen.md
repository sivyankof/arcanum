# Спека 01 · Экран «Сегодня» = эталонный дизайн

Статус: частично реализована, остаток — см. «Дополнение» внизу · Эталон: docs/design-reference.html (вкладка «Сегодня») · Значения: docs/design-system.md

## Цель

Экран «Сегодня» визуально неотличим от эталона: фон, типографика, кольца, композиция, анимации.

## Что делаем

1. **Шрифт**: подключить Cormorant Garamond 500/600 (expo-font + @expo-google-fonts/cormorant-garamond).
   Заголовок экрана, название карты, текст значения → Cormorant (размеры — по design-system.md, раздел 2).
2. **Компонент <Screen>** (src/components/Screen.tsx): LinearGradient bgTop→bg (радиальность имитируем
   вертикальным градиентом с остановкой 60%) + 5 звёзд ✦ (Text, позиции фиксированы, opacity-анимация
   0.15→0.65, цикл 4s, задержки 0/0.7/1.4/2.1/2.8s, только тёмная тема) + ScrollView с паддингами
   (24 гориз., низ 120). Перевести на <Screen> ВСЕ 5 табов (единый фон — половина «дорогого вида»).
3. **Заголовочный блок**: Overline-дата («ПЯТНИЦА · 8 АВГУСТА» — через toLocaleDateString, uppercase,
   letterSpacing 3) → Display XL «Карта дня» (Cormorant 30) → разделитель: линия-градиент со звёздочкой
   по центру (как .rule в эталоне).
4. **Строка луны**: «☽ Растущая луна · 15-й лунный день» под разделителем (Body, muted, по центру).
   Расчёт фазы: локальный алгоритм (синодический месяц 29.53059 дней от эталонного новолуния
   2000-01-06 18:14 UTC; фазы: новолуние <1.85д, растущая <14.77, полнолуние <16.61, убывающая — остальное;
   лунный день = floor(возраст)+1). Файл src/lib/moon.ts + юнит-проверка в комментарии.
5. **Кольца вокруг карты**: два пунктирных круга (react-native-svg Circle strokeDasharray="2 6",
   цвет ring из темы — ДОБАВИТЬ токен ring: #39426f / #d8c89e в theme.ts) диаметрами ~1.5 и ~1.72 ширины
   карты; вращение 70s и 100s реверс (Reanimated, linear, infinite); на каждом кольце звёздочка ✦.
   Реализация: компонент src/components/CardRings.tsx, absolute за картой.
6. **Каскад появления**: useFadeUp(index) — opacity 0→1 + translateY 14→0, 450ms cubic-out,
   stagger 70ms (дата=0, заголовок=1, луна=2, пилюли=3, карта=4). Хук в src/hooks/useFadeUp.ts.
7. **Пилюли серия/XP**: по эталону — огонёк 🔥 с «дыханием» (scale 1→1.18, 1.3s, infinite),
   XP-строка «Уровень N» + полоса-градиент (пока мок: уровень 1, 0 XP — реальные уровни в задаче 08).

## Что НЕ делаем (за рамками спеки)

Вечерняя рефлексия (06), заметка к карте (05), кнопка сброса (02), блик при перевороте (motion-spec §7 —
отдельным шагом после), изменение логики draw/streak.

## Критерии приёмки

- [x] Заголовки на всех экранах — Cormorant Garamond (включая названия карт).
- [x] Все 5 табов на едином градиентном фоне; в тёмной теме мерцают звёзды, в светлой — нет.
- [ ] Под заголовком — корректная фаза луны (сверить с любым лунным календарём на сегодня и ±3 дня).
- [x] Вокруг карты дня — два медленно вращающихся пунктирных кольца со звёздочками; не дёргаются, 60fps.
- [x] Элементы экрана появляются каскадом при входе на таб.
- [ ] Пилюли серия/XP — ряд из двух, как в эталоне.
- [ ] `npm test` зелёный (тесты фаз луны — первые юнит-тесты проекта).
- [ ] Светлая тема: всё читаемо, ничего не «пропало» (проверить каждый элемент).
- [ ] tsc чистый; скролл плавный; рядом с эталоном в браузере — «не отличить».
- [ ] Скриншоты 390×844 в обеих темах в `docs/screenshots/01/` (хвост со спеки 11 закрывается здесь же).

## Дополнение (09.08.2026): статус реализации и остаток

Пункты 1–3, 5–7 «Что делаем» реализованы (спеки 11 и коммиты по motion-spec). Отличия от буквы спеки,
принятые по ходу: компонент фона называется `ScreenBg` (не `Screen`, скролл остался в экранах),
каскад — компонент `FadeUp` (не хук `useFadeUp`), кольца — обычные View с dashed-рамкой (не SVG),
UI-шрифт — Manrope (решение спеки 11). Пилюля серии есть, XP-пилюли нет.

### Остаток 1 · Луна: модуль + строка на «Сегодня»

- `src/lib/moon.ts` (новый): чистые функции без побочных эффектов. Формула — logic-spec §6:
  возраст = (момент − 2000-01-06T18:14Z) mod 29.53059 суток; фаза: <1.85 новолуние · <14.77 растущая ·
  <16.61 полнолуние · иначе убывающая; лунный день = floor(возраст)+1. Расчёт от текущего момента
  (не от полуночи) — осознанно, так в logic-spec.
- Строка в `app/(tabs)/index.tsx` под `<Rule />` — по `.moonrow` эталона: «☽ **Растущая луна** · 8-й лунный день»;
  fontSize 13, цвет muted, фаза — цвет head, weight 600; по центру, marginTop 12.
- Строки — в i18n (оба языка): фазы «Новолуние / Растущая луна / Полнолуние / Убывающая луна»
  (en: New moon / Waxing moon / Full moon / Waning moon), лунный день ru «N-й лунный день», en «lunar day N».

### Остаток 2 · Тестовая инфраструктура (первая в проекте) + тесты луны

- jest-expo по официальному гайду Expo SDK 54 (unit testing); зависимости в devDependencies,
  версии совместимые с SDK 54 (`npx expo install`); script `"test": "jest"`.
- `src/lib/__tests__/moon.test.ts`: детерминированные кейсы от эпохи —
  эпоха (2000-01-06T18:14Z) → новолуние, день 1; эпоха+2 сут → растущая; эпоха+15 сут → полнолуние;
  эпоха+17 сут → убывающая; эпоха+29.6 сут → новолуние нового цикла, день 1;
  границы: эпоха+1.84 → новолуние, эпоха+1.86 → растущая (и аналогично для 14.77 / 16.61).
  Сверку с реальным лунным календарём на сегодня делает ревью (критерий приёмки выше).

### Остаток 3 · XP-пилюля рядом с серией

- Ряд по `.pills` эталона: flexDirection row, gap 10, marginTop 14; пилюля серии flex 1,
  XP-пилюля flex 1.5. Сами пилюли — как сейчас в StreakPill (panel/line, радиус 15, паддинги 10/13).
- Контент XP-пилюли: строка «Уровень 1 · Любопытная» (en «Level 1 · Curious») — fontSize 11,
  цвет head, bold (титулы уровней — logic-spec §4, в i18n оба языка); под ней полоса прогресса
  по `.xline`: высота 6, радиус 3, фон line; заполнение — градиент accent→accent2, ширина = прогресс.
- Мок до задачи 08: уровень 1, 0 XP → заполнение 0 (полоса-фон видна пустой). Компонент принимает
  progress 0..1, чтобы задача 08 подключила реальные данные без переделки. Анимацию заполнения
  (fill 1.5s, delay .5s, cubic-bezier(.25,1.2,.4,1)) заложить, при 0 она невидима — это ок.
- Серия остаётся в StreakPill; XP — новый компонент рядом (`src/components/XpPill.tsx`),
  ряд собирается в index.tsx. Общие стили пилюль не дублировать (вынести, если понадобится дважды).

### Остаток 4 · Каскад

Индексы FadeUp на «Сегодня»: 0 — дата+заголовок+Rule, 1 — строка луны, 2 — ряд пилюль, 3 — карта
(соответствует d1–d4 эталона).
