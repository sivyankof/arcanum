# Спека 72 · Учебный главный экран (ответ на второй отказ Apple 4.3(b))

Статус: согласована, реализована (19.09.2026, финальное ревью ветки закрыто) · Ветка: `feat/72-learning-home` · Persist: **не меняется (12)**
· Детальный план: `docs/plans/72-learning-home.md` (пишется после согласования спеки)
· Контекст отказа: `docs/specs/69-apple-review-reply.md`, кадр ревьюера `docs/screenshots/69/apple-reviewer-0918.png`

## Цель

Первое впечатление от приложения — «учебный курс по таро», а не «гадание с лунной астрологией».
Ревьюер Apple 18.09 не ушёл дальше первого экрана (серия 0, уровень 1) и увидел: заголовок
**Card of the Day**, рубашку с **TAP TO REVEAL**, строку **Waxing moon · lunar day 8**, полумесяц на
вкладке Spreads. До курса (вторая вкладка) он не дошёл. Перед этим онбординг спросил у него дату
рождения и «открыл личный аркан» — нумерологический механизм.

Задача меняет порядок и подачу, **не убирая функций**: урок становится героем первого экрана, карта дня —
ежедневной практикой на своём экране, луна уходит к лунным раскладам, онбординг рассказывает про курс.
Изменения — для всех платформ (решение Артёма 18.09): один продукт, один макет.

⚠️ Extended Review: ту же сборку с теми же метаданными отправлять нельзя. Эта сборка обязана отличаться
ЗАМЕТНО — и на первом экране, и на витрине.

## Решения брейншторма (Артём, 18.09)

| Вопрос | Решение |
|---|---|
| Глубина | Средняя: учебный главный экран, функции не теряем |
| Платформы | Все (iOS — buildNumber 4 под версией 1.0; Android — обновлением после публикации выпуска 6, вне задачи) |
| Луна | Вход в календарь переезжает во вкладку раскладов |
| Главный экран | Урок — герой, «Повторение», ниже компактная «Карта дня» → отдельный экран |
| Апелляция / звонок | Не делаем, сразу новая сборка |
| Доп. пункты (онбординг, «лунный день», Review Notes, категории) | Включены в задачу |
| Новая функция | Игра **«Угадай карту по фрагменту»** — включена в задачу (единственная из восьми предложенных идей) |
| Игра: сколько карт | 22 старших аркана, по 2–3 фрагмента (третий — где нашлась узнаваемая деталь; всего 61), решение Артёма 19.09 + слепая проверка; младшие — в 1.0.1 данными, без правки кода |
| Игра: Premium | Бесплатная целиком; `premium.ts`, пейвол и состав подписки не трогаем |

#### 2.1 Чистая функция `nextLessonSummary`

`src/lib/courseProgress.ts`, рядом с `nextLessonId` (она её и использует):

```ts
export interface NextLessonSummary {
  lesson: CourseLesson | null;   // null = курс пройден
  moduleIndex: number;           // с нуля; у пройденного курса — последний модуль
  lessonNumber: number;          // сквозной номер урока по курсу, с единицы
  total: number;                 // 32
  doneCount: number;
  pct: number;                   // Math.round(doneCount / total * 100)
}
export function nextLessonSummary(modules: CourseModule[], progress: LessonProgressMap): NextLessonSummary
```

Состояние героя (`start|continue|locked|done`) решает экран из `summary` + `lessonLocked(...)` —
`premium.ts` остаётся единственным источником решения о доступе (контракт `premiumSources`).

Юнит-тесты (в том же коммите, кейсы): пустой прогресс → `m1l1`, №1, 0 %; пройден m1 (4 урока) → `m2l1`,
№5, 13 % (4/32 = 12.5 → 13); пройдено 31 → №32, 97 %; пройдено 32 → `lesson: null`, 100 %;
прогресс с «дыркой» (m1l1, m1l3 пройдены, m1l2 нет) → `m1l2`, №2, `doneCount` 2; пустой курс `[]` →
`lesson: null`, `total` 0, `pct` 0 (без деления на ноль). Мутации: сквозной номер → номер внутри модуля;
`round` → `floor` — тесты обязаны покраснеть.

### 5. Онбординг — про курс, без даты рождения

Было: 1) заставка + дисклеймер → 2) «Немного о вас»: имя + дата рождения («Дата рождения откроет ваш
личный аркан») → 3) аркан рождения → страница карты. Стало — **два шага**:

1. **Заставка** — как есть (эмблема, `ob.sub`, дисклеймер `ob.disclaimer` без правок — Apple 1.4.1),
   CTA `ob.start`: «НАЧАТЬ ПУТЬ» → **«НАЧАТЬ ОБУЧЕНИЕ» / «START LEARNING»**.
2. **«Как устроен курс»** (`ob.howTitle`): три строки (значок из существующих + Body):
   `ob.how1` «32 урока по пять минут — от устройства колоды до раскладов»,
   `ob.how2` «После каждого урока — короткая викторина»,
   `ob.how3` «Тренажёр сам напомнит, какие карты пора повторить»;
   ниже поле имени (как сейчас: `ob.nameLabel`, `ob.namePlaceholder`, необязательно);
   CTA `ob.toCourse` «К ПЕРВОМУ УРОКУ» → `completeOnboarding(name)` → гард уводит на «Учёбу»,
   где герой — «Начать урок». Принудительно в урок НЕ заталкиваем.

- Шаг 3 (аркан рождения), `DatePicker` и переход `router.push('/card/[id]', from:'today')` из онбординга
  удаляются. **Аркан рождения как функция остаётся**: дата вводится в Настройках (строка «Дата рождения»,
  задача 59), карточка аркана — в профиле (`BirthArcanaCard`). Проверить в 6б: профиль без даты рождения
  показывает приглашение её указать (если нет — добавить пустое состояние карточки со ссылкой в настройки).
- Удаляются ключи, потерявшие потребителей: `ob.aboutTitle`, `ob.aboutLead`, `ob.birthLabel`,
  `ob.birthPlaceholder`, `ob.pickTitle`, `ob.openArcana`, `ob.continue`, `ob.learnMore` — каждый только
  после грепа «0 потребителей» (`ob.birthOverline` и `ob.namePlaceholder` живут дальше: страница карты
  и настройки).
- Сигнатура `completeOnboarding(name, birthDate?)` не меняется (второй аргумент просто не передаём) —
  persist не трогаем.

### 10. Игра «Угадай карту по фрагменту» (новая функция)

Зачем: Apple просит «unique experience not already found on the App Store». Игра на узнавание символов
колоды — учебная механика, которой нет у гадательных приложений, видна с первого экрана и даёт кадр витрины.

**Механика.** На экране — квадратный увеличенный фрагмент изображения карты (фонарь Отшельника, лев Силы)
и четыре варианта-названия. Ответ → верный вариант подсвечен `success`, неверный выбранный — `danger`
(токены темы), фрагмент плавно (300 ms, `EASE`) «отъезжает» до целой карты с именем → кнопка «ДАЛЕЕ».
Сессия — **10 вопросов**, карта в сессии не повторяется; итог — существующий `ResultPanel`
(«7 из 10», XP, «ЕЩЁ РАЗ» / «ГОТОВО»). Хаптика: верно — успех, неверно — обычный тап
(имена функций сверить с `haptics.ts`).

**XP.** +`XP_REVIEW` (1) за каждый верный ответ — существующая константа, новых правил XP не вводим
(решение 22 «XP в v1 не меняем» соблюдено: значения прежние, добавлен источник). logic-spec §4 — строка.
**Persist не меняется**: рекордов, истории и дневного лимита у игры нет. SM-2 игра не трогает.

**Данные — `content/fragments.json`**, доступ только через `src/lib/content.ts` (`fragments`,
`fragmentsOf(cardId)`):

```json
{ "hermit": [ { "cx": 0.62, "cy": 0.31, "size": 0.34 }, { "cx": 0.40, "cy": 0.70, "size": 0.30 } ] }
```

`cx`/`cy` — центр в долях ширины/высоты скана, `size` — сторона квадрата в долях ШИРИНЫ (квадрат в
пикселях: сканы 900 px шириной, пропорция 1.68–1.76 — страж `cardAssets.test.ts`). Текстов в файле нет —
редактору писать нечего. Пул вопросов = все пары (карта, фрагмент) из файла; в 1.0 — 61 фрагмент на
22 старших аркана (2–3 на карту, переменное количество — третий только там, где прошёл слепую
проверку, решение 19.09). Пул НЕ зависит от «изучено»: игра доступна со свежей установки.

⚠️ **Полоса подписи.** У сканов внизу напечатано имя карты, вверху — номер (тот самый дефект задачи 58).
Фрагмент обязан лежать вне обеих полос: границы замерить по сканам (яркостный профиль, как в
`fetch_card_scans.py`), записать ЧИСЛАМИ в контракт-тест. Имя в кадре = ответ на экране.

**Чистый модуль `src/lib/fragmentGame.ts`** (без react/expo, под тестами):
- `buildFragmentSession(pool, rng, size = 10)` → вопросы `{ cardId, box, options: string[4], correct }`:
  карты без повтора, у карты случайный из её фрагментов, три дистрактора — другие карты пула,
  варианты перемешаны общим `shuffle(items, rng)`; в пуле меньше 4 карт → пустая сессия (а не падение);
- `fragmentLayout(box, view, imageRatio, t = 0)` → `{ width, height, left, top }` для `Image` внутри
  `overflow: hidden`-квадрата (кроп без нарезки файлов: картинки остаются как есть, `cardImages.ts` не
  трогаем); `t ∈ 0..1` даёт промежуточный кадр «отъезда» до целой карты;
- `sessionScore(log)` → `{ right, total, xp }`.
Юнит-тесты: детерминизм по сид-`rng`; нет повторов карты; `correct` указывает на верное имя при любой
перестановке (⚠️ класс дефекта задач 29/31 — мутация «перемешали варианты, не пересчитав индекс» обязана
покраснеть); геометрия: квадрат у края скана не вылезает за картинку; `t = 1` — карта вписана целиком.

**Контракт-тест `fragments.test.ts`**: у каждого из 22 старших арканов ≥ 2 фрагмента, всего ≥ 44; id
существуют в колоде; квадрат целиком внутри скана и вне полос подписи/номера; `size` в пределах
0.22–0.45 (меньше — каша из пикселей, больше — узнаётся вся композиция); любые два фрагмента одной
карты перекрываются < 50 %.
Мутации: фрагмент на полосе имени, несуществующий id, карта с одним фрагментом.

**Инструмент `scripts/fragment_sheet.py`**: рисует контакт-лист всех фрагментов с подписями
(`docs/screenshots/72/fragments-sheet.jpg`) — глазами проверяется то, что тест не видит: фрагмент
узнаваем и однозначен (не «кусок неба»), **без наготы** (Звезда, Солнце, Влюблённые, Дьявол, Суд, Мир —
брать детали без фигур), не выдаёт ответ надписью. Разметку делает сессия, **«ок» по листу — Артём и редактор**.

**Экран `app/fragment.tsx`**: стек под гардом онбординга (`transparentHeader`, `stackTopPad`),
параметр `from: 'learn' | 'practice'` → `headerBackTitle`; уход посреди сессии — без диалога (терять
нечего, XP начисляется по ходу). Фрагмент — квадрат `min(W − 48, 300)`, радиус 16, рамка `line`,
свечение `glowShadow` как у карты дня; варианты — четыре кнопки-строки во всю ширину — общий стиль с
вариантами викторины урока: **взять оттуда, не копировать** (если там стиль локальный — вынести в общий
компонент `OptionButton` и перевести урок на него; значения — те, что уже стоят в уроке).

**Входы**: `FragmentPanel` (геометрия `moduleBox`; overline `game.overline` «ИГРА», заголовок Display M
`game.title` «Угадай карту», подстрочник `game.sub` «Узнайте аркан по детали рисунка», шеврон) — на
«Учёбе» (п. 2.6) и первым блоком ленты на «Практике», под строкой луны.

**Строки** `game.*` — четыре языка (es/pt — в волну вычитки 68): `overline`, `title`, `sub`,
`question` («Какая это карта?»), `resultLine` («ВЕРНО {{right}} ИЗ {{total}}»), `again`. Кнопка
«Далее» и «Готово» текст не заводят отдельно — переиспользуют `lesson.next` и `review.done`
(DRY-правило: третьей копии одной и той же надписи не заводим). Названия карт —
`inLang(card.name, lang)`.

**Веб ≠ натив**: кроп через `overflow: hidden` + масштаб `Image` на вебе работает, но РЕЗКОСТЬ
увеличенного фрагмента (скан 900 px, увеличение ~×3 на экране @3×) видна только на устройстве — пункт 6в.
Если на iPhone мыльно — поднять нижнюю границу `size` (контракт) и переразметить.
