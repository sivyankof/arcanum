# Arcanum · редполитика и гайд по контенту

Для всех, кто трогает тексты: редактор (жена — финальное слово по смыслу), Claude (черновики,
переводы), Артём (процесс). Тексты живут в content/*.json; править коммитами, не в обход git.

## Тон

На «вы», тепло, конкретно, без пафоса и эзотерического жаргона («вибрации», «энергии вселенной» — нет).
Мы про рефлексию и самопознание, НЕ про предсказание судьбы: «карта отозвалась», а не «предсказание
сбылось»; «на что обратить внимание», а не «вас ждёт». Трудные карты (Смерть, Дьявол, Башня, 9–10 Мечей) —
бережно: назвать трудность честно + дать опору и выход. Блоки health — только рефлексивно, ноль медицины
(риск ревью сторов). Юмор — лёгкий допустим в day_card, никогда в reversed.

## Канонический глоссарий (RU / EN)

Старшие/Младшие арканы = Major/Minor Arcana · масти: Жезлы/Wands, Кубки/Cups, Мечи/Swords,
Пентакли/Pentacles (НЕ «посохи», «чаши», «денарии») · придворные: Паж/Page, Рыцарь/Knight,
Королева/Queen, Король/King · «перевёрнутая карта»/reversed (НЕ «обратная») · расклад/spread ·
карта дня/card of the day · серия/streak (в UI: «серия») · Уэйт — «А. Э. Уэйт», колода — «Райдер–Уэйт»
(в EN: Rider–Waite–Smith допустимо). Названия карт — как в content/cards.json, не переименовывать.

## Структура блоков карты (8 шт., лимиты слов)

general 40–80 · reversed 35–60 · love/career/day_card 35–60 · finances 25–50 · health 25–40 ·
symbolism 40–80. day_card — обращение напрямую, совет на сегодня. symbolism — только то, что реально
изображено на карте Райдер–Уэйт.

## Workflow статусов

`todo → draft → reviewed → final`. draft = написан Claude · reviewed = вычитан редактором (смысл верен) ·
final = вычитан + перечитан после правок EN. Статус меняется только вперёд. Прогресс: `npm run content:stats`.

## Как редактор вносит правки (процесс)

Вариант А (основной): жена читает документ «все 78 карт» (HTML), пишет правки в любом виде
(«Императрица, любовь: убрать про быт, добавить про заботу о себе») → Артём передаёт список в
Cowork-сессию или Claude Code → правка в cards.json + статус reviewed + коммит `content: правки <карты>`.
Вариант Б: точечно сказать Claude Code голосом/текстом прямо во время разработки — тоже допустимо,
правило то же: правка = коммит со статусом.
EN после правок RU: Claude обновляет английский, чтобы смысл совпадал (не подстрочник).

## Переводы (будущие ES, PT-BR…)

Новый язык = новые ключи в name/keywords/content каждого блока + строки UI в src/lib/i18n.ts.
Порядок: перевод с EN (не с RU), нейтив-вычитка обязательна до релиза языка, глоссарий расширяется
на язык ДО начала перевода. Никогда не релизим язык со статусами draft.

## Тексты интерфейса (не контент)

Живут в src/lib/i18n.ts. Правила те же (тон, «вы»), плюс: кнопки — глагол («Вытянуть карту»),
ошибки — без вины пользователя, пуши — интрига без давления и вины (макс 2/день — инвариант).
