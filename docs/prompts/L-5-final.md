# Промт сессии L-5 · Финальная приёмка испанского и португальского

Последняя сессия трека. К этому моменту переведено всё: карты (78 × 958 блоков), UI (267 строк),
фразы, состав раскладов, курс и расклады. Задача L-5 — не переводить, а **довести язык
до состояния «готов к релизу»** и честно сказать, где он не готов.

Прочитай `docs/localization-plan.md` целиком, включая все отчёты и приёмки в конце файла.

## 1. Долги, накопленные волнами (закрыть до статусов)

Полный список — задача **28д** в `docs/backlog.md`. Коротко:
- **8 блоков Старших, где потерян вопрос читателю.** В русском «…а что забирает силы?»,
  в переводе — утверждение. Меняется жанр: вместо повода подумать приложение сообщает читателю,
  как у него дела. es: `hierophant.health`, `wheel-of-fortune.day_card`, `hanged-man.health`,
  `death.career_reversed`, `sun.health`, `judgement.career_reversed`; pt: `hanged-man.health`,
  `sun.health`. ⚠️ В испанском вопрос требует ОБОИХ знаков: «¿…?».
- **4 группы сведённых зачинов (12 блоков)**, где русский даёт три разных оборота, а перевод
  один: es «hace falta», «hay riesgo»; pt «esta carta», «olhe para».
- **Два «prima»** (`c03.finances`, `c11.finances`, es) — на усмотрение нейтива.
- Расхождения указателей у приписок сфер — список печатает
  `python scripts/check_translation.py --wave all --lang es,pt` в разделе [ОТЧЁТ].

## 2. Перенос корпусных проверок на новые языки — ОБЯЗАТЕЛЬНЫЙ пункт

`scripts/check_canon.py` жёстко ограничен `LANGS = ("ru", "en")`: **ни одна из его 11 проверок
не видит es и pt**, и зелёный прогон об этих языках не говорит ничего. Объявить «сквозные
автопроверки всей базы пройдены» без переноса — самообман.

- Переносимы как есть: зачины (7), обороты-тики (8), слова карт (10), длины (1) — последним
  нужны нормы по языкам, снятые с корпуса, а не выдуманные (урок задачи 31: общие лимиты
  на два языка объявляли нарушением 73 нормальных русских текста).
- Непереносимы без словарей: рамка предсказания (2), жаргон (3), медицина (4), род читателя (5),
  глоссарий (6). Для них нужны испанские и португальские списки формулировок — это работа
  нейтива, а не перевод русских регулярок. ⚠️ Род читателя в романских языках — БОЛЬШАЯ проблема,
  чем в русском: он вылезает в согласовании прилагательных («quedarte sola», «cansado»),
  и в шаге 0 таких мест нашлось ~33 на одних Старших.
- Чего перенести нельзя — честно назвать неприменённым в отчёте, а не «пройденным».

## 3. Контрольный обратный перевод по всей базе

Выборка ~10% блоков КАЖДОГО языка, переводчик не видит оригинала, сверка с каноном.
Смещать выборку в сторону `health`, `health_reversed`, `day_card` — там цена ошибки выше всего
(медицинская рамка и обещания — риск при ревью сторов).

## 4. Статусы — последним шагом, только после всего остального

```
python scripts/set_status.py reviewed --lang es --dry-run   # сначала посмотреть
python scripts/set_status.py reviewed --lang es
python scripts/set_status.py reviewed --lang pt
```
⚠️ **Только `--lang es` / `--lang pt`.** Без ключа скрипт двигает канон `ru`/`en`, а он
вычитан человеком и трогать его нельзя — иначе вернётся ровно та дыра, из-за которой английский
не читал никто (задача 28а).
⚠️ Статус НЕ выдаётся языку без текста — скрипт сам называет пропущенные числом. Если число
не ноль, значит что-то не долито: разобраться, а не двигать дальше.
На 20.08 сухой прогон по картам даёт 1036 единиц (958 блоков + 78 наборов слов); после L-4
добавятся теория (32) и викторины (32).
