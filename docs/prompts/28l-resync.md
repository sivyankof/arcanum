# Промт задачи 28л · Перезаливка es/pt блоков, изменённых правками канона 28г и 28в

Правки канона (задачи 28г и 28в, 21.08, коммиты 53d429b и 76232b7) изменили русский — и в
нескольких местах английский — текст 21 блока карт. Их испанский и португальский переводы
остались со СТАРЫХ формулировок и разошлись с каноном. Нужно перевести эти блоки заново.
Расхождение стилистическое, а не смысловое (правки снимали повторы и тавтологии), поэтому
задача маленькая, но переводы в этом проекте пишет только Cowork — отсюда этот промт.

Прочитай сначала: `docs/content-guide.md` (норма языка, реестр зачинов-указателей, глоссарии
es/pt), отчёты L-1…L-5 в конце `docs/localization-plan.md` (там же — чем кончались прежние
волны и какие классы дефектов ловились).

## Какие блоки

Объединение адресов из двух списков «было → стало»:
- `docs/specs/28g-changed-addresses.md` (4 блока),
- `docs/specs/28v-changed-addresses.md` (17 блоков).

Адрес вида `temperance.day_card.ru` — это карта `temperance`, блок `day_card`; языковой
суффикс отбрось: блок перезаливается на ОБА языка (es и pt) один раз, независимо от того,
правился ли в каноне только русский или оба языка. Пересечений между списками нет — всего
21 блок. «Стало» в списках — для сверки; **источник истины — актуальный `content/cards.json`**
(правки канона там уже применены).

## Правила (первым пунктом — норма языка, урок L-3)

1. **Норма языка:** es — нейтральный латиноамериканский, БЕЗ пиренейских форм (никакого
   vosotros/os/vuestro); pt — бразильский, без европеизмов. Проверь свой текст на это ДО сдачи.
2. Перевод пишется заново с ПАРЫ источников ru + en, а не правкой старого перевода по месту:
   точечная правка оставляет следы старой формулировки.
3. Зачин-указатель сферного блока — по реестру формул из `content-guide.md` (для es/pt реестр
   записан шагом 0 L-2). Где в русском каноне указателя нет — в переводе он тоже свободный.
4. Род читателя безличный: в романских языках он вылезает в согласовании прилагательных
   со связкой — держи формы без рода.
5. Перевод ≠ дословный английский; смысл сверяй по обоим источникам, тон — content-guide.
6. Канон ru/en не трогать ни байтом. `name`/`keywords`/`search`/`wordsStatus` не трогать.
7. **Статусы es/pt этих блоков ОСТАВИТЬ `reviewed`** — решение задачи 28л (бэклог): на релиз
   расхождение не влияло, отчёт готовности не ломаем. Ничего не понижать и не поднимать.
8. Формат файла: JSON с отступом 1 (как лежит), порядок языков в блоке ru → en → es → pt.
   Дифф обязан состоять только из изменённых es/pt строк — перестановка ключей запрещена.

## Проверки перед сдачей (python ≥ 3.10 достаточно — задача 28з закрыта)

1. Список своих правок — в `docs/specs/28l-changed-addresses.md` в формате
   `check_edits.py` (`## карта.блок.es` / `- было:` / `- стало:`; образец —
   `docs/specs/28v-changed-addresses.md`).
2. `python scripts/check_edits.py docs/specs/28l-changed-addresses.md` — правка обоих переводов
   при нетронутом каноне для него норма (пары считаются внутри семьи), находки тавтологий
   и повторов с соседним блоком — чинить и прогонять снова.
3. `python scripts/check_translation.py --wave all --lang es,pt --status reviewed` — обязан
   остаться зелёным (если гоняешь после коммита поставки — добавь `--no-git`).
4. `npm test` (контракт-тесты контента) и `npx tsc --noEmit` — зелёные.

## Отчётность

Отчёт сессии — в конец `docs/localization-plan.md` (как у прежних волн): сколько блоков
перезалито, находки, вывод каждой проверки. Коммит:
`content: перезаливка es/pt блоков после правок канона 28г/28в (задача 28л)`.
Приёмку после сдачи делает сессия Claude Code (как у L-1…L-5).
