# Промт для сессии реализации задачи 53а (Arcanum Premium)

Реализуй задачу 53а «Монетизация: Arcanum Premium» по готовым документам — брейншторм, спека, план и макет
уже сделаны и согласованы, заново их не переписывай.

**Прочитай в таком порядке, прежде чем трогать код:**
1. `CLAUDE.md` и `AGENTS.md` (процесс, жёсткие правила, общие модули).
2. `docs/specs/53-premium.md` — спека, согласована Артёмом 22.08 (решения: лимит тренажёра 10 карт/день;
   истечение подписки ничего не отбирает; подписка живая с первой версии, флага нет; право НЕ в бэкапе).
3. `docs/plans/53-premium.md` — детальный план, 10 задач с кодом и тестами. Выполнять задача за задачей.
4. `docs/lessons.md` — разделы §1 (стор/persist/бэкап), §5 (навигация), §8 (тесты), §9 (веб-проверка).
5. Макет: `docs/design-reference.html` — вью `v-paywall` (кнопка «Premium» в демобаре ходит по трём
   состояниям) и точки входа; скриншоты `docs/screenshots/53-paywall/`. Макет принят 22.08, значения
   из его CSS уже перенесены в план (задача 5); при расхождении плана с макетом — замер по CSS макета.

**Как работать:**
- Ветка `feat/53-premium` от `main` (сейчас `f66b6b7`, 1501 тест в 40 сьютах, `tsc` чист).
- Subagent-driven development: на каждую задачу плана — свежий сабагент **sonnet** (явно указывать
  модель), после каждой задачи — ревью (сверка с планом и спекой), затем следующая. Задачи 1–4 — логика
  без UI, 5–8 — экран и гейты, 9 — контракт-тест и документы, 10 — веб-проверка 6а/6б и сценарий лайв.
- После каждого шага с кодом — `npx tsc --noEmit`; перед каждым push — `npm test` зелёный. Новая формула —
  тест в том же коммите; тест обязан краснеть на сломанном коде (проверяй мутацией хотя бы у задач 1–3).
- `SCHEMA_VERSION` 10 → 11 ровно один раз (задача 3); `doneCount` внутри `reviewDay` — слияние руками
  в `migrate` и `parseBackup` (`mergeReviewDay`); `premium` в бэкап не входит.
- Экраны не читают `free`/`premium.active` сами — только `src/lib/premium.ts` (задача 9 стережёт грепом).
- Новая UI-строка — сразу в четыре языка `i18n.ts` (тексты es/pt для пейвола лежат в плане, задача 4).
- `package.json`/`app.json` не трогать: новых пакетов в 53а нет. RevenueCat — отдельная задача 53б.
- Веб-проверка (задача 10): dev-сервер поднимать заново с `--clear`, доставку правок проверять грепом
  по бандлу; Playwright из кэша npx (команда в `AGENTS.md`); красный прогон обязателен (снять гейт
  маршрута урока — прямая ссылка обязана открыть урок и уронить проверку); скриншоты в
  `docs/screenshots/53/`, обе темы, 390×844.
- Коммиты — русские, по одному на задачу плана, без упоминаний ИИ; push после зелёных тестов.
- Сценарий лайв-проверки для Артёма — в конец спеки; merge в `main` только после его ✓.

**Контрольные точки, где остановиться и показать Артёму:** после задачи 5 (пейвол виден в вебе — скриншоты
А/Б в обеих темах) и после задачи 10 (отчёт веб-проверки + сценарий лайв). Вопросы — по-русски.
