# Промт сессии L-2 · Младшие арканы, Жезлы + Кубки → ES/PT

Ты продолжаешь трек локализации Arcanum. Первым делом прочитай `docs/localization-plan.md`
целиком — включая отчёты L-0 и L-1 в конце файла: правила этой сессии выведены из их находок.
Глоссарии и нормы языков — `docs/content-guide.md` (разделы ES/PT из L-0).

## Предусловие (проверить до старта)

L-1 принята: `content/cards.json` в рабочем дереве совпадает с HEAD (нет незакоммиченных
изменений). Если файл изменён — СТОП, сообщи Артёму: приёмка предыдущей сессии не завершена.

## Объём

28 карт × 2 языка (es, pt): **Жезлы `w01`–`w14` и Кубки `c01`–`c14`** в `content/cards.json`.
На карту и язык, атомарно одним куском:
- `name` + `keywords` (ровно 4) + `search` (8–12) + `wordsStatus`;
- **12 блоков**: general, reversed, love, career, finances, health, day_card, symbolism,
  love_reversed, career_reversed, finances_reversed, health_reversed.
  ⚠️ У младших НЕТ `birth_path` — не добавлять.

Итого 672 текста + слова. Источники перевода: `ru` (основной) + `en` (контрольный).
Поле `source` (Уэйт) — служебное, не трогать и не переводить.

## Модели (план локализации, раздел «Модели»)

Массовые блоки — средняя модель (Sonnet) с эталонами стиля в промпте: взять 3–4 старшие карты
из L-1 как образец тона es/pt. Вычитка, обратный перевод и шаг 0 — старшая модель (Opus).

## Шаг 0 — зачины-указатели (решение Артёма 20.08 по «второму флагу» L-1)

Конвенция канона распространяется на es/pt: блоки сфер открываются ЕДИНООБРАЗНЫМ
зачином-указателем (в ru «В любви…» ×21 — это навигация, не дефект). Что сделать:
1. Выбрать по одной формуле указателя на сферу × язык (love/career/finances/health;
   например «En el amor…» / «No amor…» — точные формулы на твой выбор нейтива)
   и записать их в глоссарий `content-guide.md`.
2. Корректирующий проход по УЖЕ залитым 22 старшим L-1: привести зачины сферных блоков
   es/pt к этим указателям. Менять только зачин, не переписывая остальной текст.
3. Жезлы и Кубки переводить сразу с указателями.
Правило разнообразия теперь применяется к тексту ПОСЛЕ указателя: корпусная проверка повторов
для сферных блоков смотрит первые два слова после формулы. Для general/day_card/symbolism
указателей нет — там прежняя проверка первых двух слов.

## Правила заливки (те же, что в L-1 — не ослаблять)

- **Атомарность**: карта × язык заливается одним куском после валидации всего пакета;
  карта с любым дефектом не заливается вовсе. Асимметрий «блок es без name.es» — 0
  (контракт-тест `cardsContent.test.ts` уронит приёмку).
- **Статусы**: es/pt = `draft` (блоки и `wordsStatus`). Статусы и тексты ru/en НЕ трогать.
  До `reviewed` статусы поднимает только L-5.
- **Порядок ключей**: es после en, pt после es; существующие ключи не переставлять.
- Пустые строки `""` запрещены (это «язык есть и он пустой», контракт-тест ловит).
- Карты вне объёма (Мечи, Пентакли, старшие сверх шага 0) не задевать.
- Имя карты в текстах = `name.es`/`name.pt` ЭТОЙ ЖЕ карты; упоминания других карт — по их `name`
  того же языка (урок задачи 31: два имени одной карты на одном экране).
- Масти по глоссарию: ES Bastos/Copas/Espadas/Oros; PT-BR Paus/Copas/Espadas/Ouros.
- ES — нейтральная латиноамериканская норма, tú; PT — бразильская, você.

## Качество: уроки L-1, применить при написании, а не чинить потом

- **Тире-калька**: `symbolism` писать нормальными предложениями с глаголами СРАЗУ
  (в L-1 пришлось перестраивать 22 PT + 15 ES блоков).
- Идиомы не калькировать («на коротком поводке» → `de rédea curta`, не «na coleira curta»).
- Дописанных обстоятельств сверх ru/en — 0 (в en задачи 25 переводчик добавлял «At work» от себя).
- Длины: ±20% от английского блока.
- **Терминология стихий**: Жезлы = огонь, Кубки = вода — как в курсе М4 (числовая ось
  Туз=семя … Десятка=предел). Термины стихий в текстах не переизобретать.
- Согласование рода: «карта» — la carta / a carta (она); «отозвалась» = resonó / ressoou.

## Проверки перед сдачей (по каждому языку ОТДЕЛЬНО)

- Корпусная проверка зачинов — по ВСЕМУ корпусу es/pt (50 карт: старшие L-1 + новые),
  а не только по новой пачке; сферные блоки — по тексту после указателя.
- Пустых 0 · кириллицы 0 · keywords ровно 4 · search 8–12 · длины ±20% от en ·
  22+28 карт атомарно целые · JSON валиден.
- Обратный перевод выборки ~30 блоков на русский вслепую (переводчик не видит оригинала).
- Финальная вычитка нейтивами обоих языков.

## Флаги и отчётность

- Дефекты КАНОНА ru/en не править (иначе 4 языка разойдутся) — перечислить в отчёте,
  как L-1 сделала с предсказательными формулировками.
- Отчёт сессии дописать в конец `docs/localization-plan.md` (формат — как отчёты L-0/L-1).
- Git: изменения оставить в рабочем дереве НЕзакоммиченными — коммитит приёмка CC-L2.
  Параллельно могут работать другие сессии: трогать только `content/cards.json`,
  `docs/localization-plan.md` и раздел глоссария в `docs/content-guide.md`.
- Файлы с кириллицей не гонять через PowerShell-конвейер (Get-Content/Set-Content портят
  кодировку) — только python или прямое редактирование.
