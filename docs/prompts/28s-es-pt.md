# Промт задачи 28с · Перезаливка es/pt у дистракторов, изменённых задачей 28р

Задача 28р (23.08) переписала дистракторы викторины — неверные варианты, которые выдавали себя
ФОРМОЙ, а не содержанием: категоричным словом («всегда», «полностью», `never`, `entirely`),
нелепостью, уходом от заданного вопроса или длиной. Правились ТОЛЬКО русский и английский;
испанский и португальский у этих вариантов остались от старой формулировки. Сейчас у испанца
и бразильца те же вопросы снова решаются «по форме». Нужно перевести эти варианты заново.
Переводы в проекте пишет только Cowork — отсюда этот промт.

Прочитай сначала: `docs/content-guide.md` (норма языка, глоссарии es/pt), отчёт L-4 (курс)
в `docs/localization-plan.md`, спеку `docs/specs/28r-guessable-second-pass.md` — там записано,
ЧТО именно чинила правка и почему. Прецедент этой же работы — `docs/prompts/28p-quiz-distractors.md`
(задача 28п, закрыта 23.08): правила те же, отличается только список адресов.

## Объём — 116 адресов, 42 вопроса, только дистракторы

Список «было → стало» — `docs/specs/28r-changed-addresses.md`. Адрес вида `m3l2-q5[0].ru`:

- `m3l2` — урок (М1–М2 лежат в `content/quiz-m1-m2.json`, М3 — `quiz-m3.json`, М4 — `quiz-m4.json`,
  М5 — `quiz-m5.json`, М6 — `quiz-m6.json`);
- `q5` — пятый вопрос урока по порядку (счёт с единицы);
- `[0]` — индекс варианта в массиве `options` (счёт с нуля);
- языковой суффикс отбрось: вариант перезаливается на ОБА языка (es и pt) один раз, независимо
  от того, правился ли в каноне только английский или оба.
  Надёжнее искать вариант не по индексу, а по тексту «стало» из списка — он совпадает с текущим
  `ru`/`en` в JSON. **Источник истины — актуальные `content/quiz-*.json`**, правки 28р там применены.

⚠️ В списке есть адреса, где правился ТОЛЬКО английский (`.en` без парного `.ru`) — там русский
уже был без категоричности, а английский её добавлял от себя. Это девять адресов; переводу они
подлежат так же, как остальные: es/pt переводятся с пары ru+en, а не с одного языка.

## Правила

1. **Норма языка:** es — нейтральный латиноамериканский, `tú`, без пиренейских форм (никакого
   `vosotros`/`os`/`vuestro`); pt — бразильский, `você`, без европеизмов (`autocarro`, `telemóvel`,
   `ecrã`). Проверить свой текст на это ДО сдачи.
2. **Перевод пишется заново с ПАРЫ источников ru + en**, а не правкой старого перевода по месту:
   точечная правка оставляет следы старой формулировки — ровно той, которую снимали.
3. **Смысл правки 28р обязан пережить перевод.** Дистрактор — правдоподобное заблуждение,
   которое знающий человек отвергает ПО СОДЕРЖАНИЮ, а не по форме. Поэтому:
   - никаких абсолютов, которых нет в русском: `siempre`/`nunca`/`jamás`/`completamente`/`todo`/
     `nada`/`sempre`/`nunca`/`totalmente`. Если в ru «обычно достаётся тем, кто добивается трудом»,
     перевод не имеет права вернуть «sólo a quienes…»;
   - никаких нелепостей и отговорок: дистрактор звучит так, будто его мог выбрать человек,
     который учился, но понял не так;
   - дистрактор обязан отвечать НА заданный вопрос: правки класса `offtopic` снимали именно то,
     что вариант говорил не о том, о чём спрашивают, — перевод не должен вернуть это обратно;
   - длина дистрактора соизмерима с верным вариантом того же вопроса В ТОМ ЖЕ ЯЗЫКЕ: верный
     не должен становиться ни самым длинным, ни самым коротким (проверка длин — `check_canon.py`).
4. **Не трогать:** верный вариант, текст вопроса `q`, пояснение `explain`, русский и английский,
   вопросы вне списка. **Порядок вариантов не менять ни в одном языке** — `correct` индексный,
   переставленные варианты делают верным дистрактор при валидной схеме и молчащем тесте
   (проект платил за это в задачах 29 и 31).
5. Порядок ключей внутри варианта `ru → en → es → pt`, пустых строк нет.
6. ⚠️ **Формат файлов:** `quiz-*.json` — отступ **1**; правишь скриптом — `indent=1`,
   `ensure_ascii=False`; правишь редактором — проверь `git diff --stat`: затронутых строк должно
   быть порядка 230, не тысячи (иначе поехали переводы строк или порядок ключей).
7. **Статусы** (`status` в шапке `quiz-*.json` и `quizStatus` в `course.json`) остаются `reviewed`
   для всех языков, как в 28п: меняется формулировка дистрактора, не смысл вопроса.
8. После правки черновиков **обязательно** `python scripts/merge_quiz.py` — приложение читает
   собранный `content/course.json`, иначе там останется старый es/pt.
9. Список СВОИХ правок — `docs/specs/28s-changed-addresses.md` в том же формате (адрес
   с суффиксом `.es`/`.pt`, «было → стало»): это вход для `check_edits.py`, без него приёмка
   не запускается.

## Проверка перед сдачей (все зелёные)

```
python scripts/merge_quiz.py
python scripts/check_translation.py --scope course --lang es,pt --status reviewed
python scripts/check_canon.py --scope course
python scripts/check_edits.py docs/specs/28s-changed-addresses.md
python scripts/check_quiz_guess.py --against <ревизия до твоих правок>
npm test
```

Что чем закрыто:
- `check_translation --scope course` — полнота, `correct`, порядок вариантов, статусы, кириллица;
- `check_canon --scope course` — корпусные правила по КАЖДОМУ языку; **ориентир: 225 находок**
  (столько осталось после 28р). Стало больше — твоя волна что-то внесла;
- `check_edits` — не сломала ли правка то, что было целым. ⚠️ Класс 6 «сменилась мысль» на
  переводческой волне неинформативен by design (перевод пишется заново) — это материал для глаз;
- `check_quiz_guess --against` — **страж**: он обязан показать 0. Любая строка означает, что
  тронут верный вариант, `correct`, вопрос или пояснение, то есть перевод вышел за периметр.
  ⚠️ Сам скрипт считает категоричность и длины только по ru/en (канон), твою работу он этим
  не проверяет — за es/pt отвечает `check_canon`, там словари `dict_es.py` / `dict_pt.py`.
