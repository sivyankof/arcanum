# Промт сессии L-4 · Курс и расклады → ES/PT

Ты продолжаешь трек локализации Arcanum. Прочитай `docs/localization-plan.md` целиком —
включая отчёты L-0…L-3 и приёмки CC-L2 в конце файла: правила выведены из их находок.
Глоссарии, реестр зачинов-указателей и нормы языков — `docs/content-guide.md`.

## Предусловие

Карты переведены целиком (78 из 78 на четырёх языках, L-1…L-3 приняты), рабочее дерево чистое.
Если `content/cards.json` изменён — СТОП: приёмка предыдущей сессии не завершена.

## Объём

1. **Теория курса** — 32 урока × 2 языка в `content/course.json`: `title` модулей (6),
   `title` уроков (32), `theory` (32) + `theory.status` = `draft` для нового языка.
2. **Викторины** — 160 вопросов × 2 языка: `q`, три `options`, `explain` у каждого.
3. **Расклады** — `content/spreads.json`: 8 раскладов × `name`, `description` и все `positions`.
   Статусов у раскладов нет — есть перевод или нет.

`content/composition.json` и `content/phrases.json` переведены ещё в L-0 — не трогать.

## ⚠️ Викторины переводятся в STAGING, а не в course.json

`merge_quiz.py` сливает `content/quiz-*.json` в `course.json` строкой `lesson["quiz"] =
questions` — то есть **заменяет массив вопросов урока целиком**. Перевод, залитый прямо
в `course.json`, будет стёрт первым же прогоном конвейера, и никакой тест этого не поймает:
схема останется валидной, просто испанский исчезнет.

Порядок работы:
1. переводить в пяти staging-файлах `content/quiz-m1-m2.json`, `quiz-m3.json`, `quiz-m4.json`,
   `quiz-m5.json`, `quiz-m6.json`;
2. в каждом файле проставить `status` нового языка (`{"ru": …, "en": …, "es": "draft"}`) —
   статус у файла ОДИН на все его уроки;
3. прогнать `python scripts/merge_quiz.py` — он перенесёт вопросы и статусы в `course.json`
   и заодно провалидирует схему (ровно 5 вопросов, 3 варианта, `correct` в 0..2, `cardId`
   существует в колоде);
4. теорию и заголовки править прямо в `course.json` — их в staging нет.

## ⚠️ Порядок вариантов викторины НЕ МЕНЯТЬ

`correct` — это ИНДЕКС в массиве `options`. Переставили варианты при переводе, не тронув
индекс, — верным ответом становится дистрактор, схема при этом валидна и контракт-тест молчит.
Проект платил за это дважды (задачи 29 и 31). Переводить вариант i строго на место i.

Из той же серии — правила, которые уже стоили правок:
- **неверные варианты нарочно содержат ересь** («точное предсказание», «higher powers»):
  это и есть вопрос. Не «улучшать» их и не смягчать;
- **верный ответ не должен быть самым длинным** — иначе его видно без знания темы. В русском
  корпусе это выравнивали руками по 51 вопросу; в переводе легко вернуть, потому что романские
  языки длиннее. Держать варианты сопоставимыми по длине;
- **`card`-вопросы** (варианты — имена карт) берут имена из `name.es`/`name.pt` колоды,
  а не переводят их заново.

## Тон и термины

- Теория — обучающий текст, а не гадание: те же запреты, что в картах (обещание результата,
  медицинская рамка), плюс канон терминов из глоссария (масти, стихии, названия карт).
- Внутренние идентификаторы уроков (`m1l2`) в тексте не встречаются и не должны появиться —
  пользователь их не видит. Проверяется грепом `m\dl\d`.
- Числовая ось мастей (Туз — семя стихии … Десятка — предел цикла) — сквозная для М4,
  термины не переизобретать между уроками.
- Упражнения сверять с ПОВЕДЕНИЕМ приложения, а не только с текстом: финальное задание курса
  однажды просило дописать строку в старую запись дневника, а правится только сегодняшняя.

## Проверки перед сдачей

```
python scripts/check_translation.py --scope course  --lang es,pt
python scripts/check_translation.py --scope spreads --lang es,pt
python scripts/content_stats.py
npm test && npx tsc --noEmit
```
Первый прогон проверяет полноту, статусы `draft`, пустые строки, кириллицу, **индекс верного
ответа и порядок вариантов против канона**, неприкосновенность ru/en. Оба режима подтверждены
мутациями. Совпадение вариантов ПО СМЫСЛУ скрипт не проверяет — если варианты всё же
переставлялись, сверить текст верного ответа до и после руками.

Плюс корпусные проверки по каждому языку отдельно (зачины вопросов, однообразие пояснений)
и обратный перевод выборки ~10% блоков вслепую.

## Отчётность

- Отчёт дописать в конец `docs/localization-plan.md` (формат — как у L-0…L-3).
- Изменения оставить в рабочем дереве НЕзакоммиченными — коммитит приёмка.
- Трогать только `content/course.json`, `content/quiz-*.json`, `content/spreads.json`,
  `docs/localization-plan.md`, `docs/backlog.md` — параллельно могут идти другие сессии.
- Файлы с кириллицей не гонять через PowerShell-конвейер (портит кодировку) — python или Edit.
