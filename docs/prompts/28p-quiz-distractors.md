# Промт задачи 28п · Перезаливка es/pt у дистракторов викторины, изменённых задачей 28е

Задача 28е (21.08) правила дистракторы викторины курса — неверные варианты ответа, которые
выдавали себя ФОРМОЙ: категоричным словом («всегда», «никогда», «полностью»), нелепостью или
короткой отговоркой рядом с развёрнутым верным ответом. Правились ТОЛЬКО русский и английский;
испанский и португальский у этих вариантов остались от старой формулировки — и сейчас у испанца
и бразильца те же вопросы снова решаются «по форме», а не по знанию карт. Нужно перевести эти
варианты заново. Переводы в проекте пишет только Cowork — отсюда этот промт.

Прочитай сначала: `docs/content-guide.md` (норма языка, глоссарии es/pt), отчёт L-4 (курс)
в `docs/localization-plan.md`, разделы «Метод» и «Как чинить» в
`docs/specs/28e-guessable-questions.md` — там записано, ЧТО именно чинила правка и почему.

## Объём — 121 адрес, 32 вопроса, только дистракторы

Список «было → стало» — `docs/specs/28e-changed-addresses.md`. Адрес вида `m1l1-q2[1].ru`:

- `m1l1` — урок (модули М1–М2 лежат в `content/quiz-m1-m2.json`, М3 — `quiz-m3.json`, М4 —
  `quiz-m4.json`, М5 — `quiz-m5.json`, М6 — `quiz-m6.json`);
- `q2` — второй вопрос урока по порядку (счёт с единицы);
- `[1]` — индекс варианта в массиве `options` (счёт с нуля);
- языковой суффикс отбрось: вариант перезаливается на ОБА языка (es и pt) один раз, независимо
  от того, правился ли в каноне только английский или оба.
  Надёжнее искать вариант не по индексу, а по тексту «стало» из списка — он совпадает с текущим
  `ru`/`en` в JSON. Пересечений в списке нет: 121 адрес — это 32 вопроса, в каждом один-два
  дистрактора. «Стало» в списке — для ориентира; **источник истины — актуальные
  `content/quiz-*.json`**, правки 28е там уже применены.

## Правила

1. **Норма языка:** es — нейтральный латиноамериканский, `tú`, без пиренейских форм (никакого
   `vosotros`/`os`/`vuestro`); pt — бразильский, `você`, без европеизмов (`autocarro`, `telemóvel`,
   `ecrã`). Проверить свой текст на это ДО сдачи.
2. **Перевод пишется заново с ПАРЫ источников ru + en**, а не правкой старого перевода по месту:
   точечная правка оставляет следы старой формулировки — ровно той, которую снимали.
3. **Смысл правки 28е обязан пережить перевод.** Дистрактор — правдоподобное заблуждение,
   которое знающий человек отвергает ПО СОДЕРЖАНИЮ, а не по форме. Поэтому:
   - никаких абсолютов, которых нет в русском: `siempre`/`nunca`/`jamás`/`completamente`/
     `todo`/`nada`/`sempre`/`nunca`/`totalmente` — если в ru «далеко не у каждого», перевод
     не имеет права вернуть «o lo tienes o no lo tienes»;
   - никаких нелепостей и отговорок: дистрактор звучит так, будто его мог бы выбрать человек,
     который чему-то учился, но понял не так;
   - длина дистрактора соизмерима с верным вариантом того же вопроса В ТОМ ЖЕ ЯЗЫКЕ —
     не вдвое короче и не длиннее всех; верный ответ не должен становиться самым длинным
     или самым коротким вариантом (проверка длин — `check_canon.py`, см. ниже).
4. **Не трогать:** верный вариант (он не менялся, и его перевод верен), текст вопроса `q`,
   пояснение `explain`, русский и английский, вопросы вне списка. **Порядок вариантов не менять
   ни в одном языке** — `correct` индексный, переставленные варианты делают верным дистрактор
   при валидной схеме и молчащем тесте (проект платил за это в задачах 29 и 31).
5. Порядок ключей внутри варианта `ru → en → es → pt`, пустых строк нет.
6. ⚠️ **Формат файлов:** `quiz-*.json` лежат с отступом **1** и переводами строк **CRLF** —
   сохранить побайтно, иначе дифф на сотни строк чистой перестановки (класс 28а/28к/51).
   Правишь скриптом — пиши `indent=1`, `ensure_ascii=False`, `newline='\r\n'`; правишь
   редактором — проверь `git diff --stat`: затронутых строк должно быть порядка 250, не тысячи.
7. **Статус файлов** (`status` в шапке каждого `quiz-*.json` и `quizStatus` в `course.json`)
   остаётся `reviewed` для всех языков, как в 28л: меняется формулировка дистрактора, не
   смысл вопроса; новых статусов не заводить.
8. После правки черновиков **обязательно** `python scripts/merge_quiz.py` — собранный
   `content/course.json` иначе останется со старым es/pt, а приложение читает именно его.
   Скрипт идемпотентен и валидирует схему; он же покажет, если порядок вариантов сбился.
9. Список СВОИХ правок — `docs/specs/28p-changed-addresses.md` в формате
   `docs/specs/28e-changed-addresses.md` (адрес с суффиксом `.es`/`.pt`, «было → стало»):
   это вход для `check_edits.py`, без него приёмка не запускается.

## Проверка перед сдачей (все четыре — зелёные)

```
python scripts/merge_quiz.py
python scripts/check_translation.py --scope course --lang es,pt --status reviewed
python scripts/check_canon.py --scope course
python scripts/check_edits.py docs/specs/28p-changed-addresses.md
npm test
```

`check_translation --scope course` сверяет полноту, `correct`, порядок вариантов, статусы и
неприкосновенность канона ru/en; `check_canon --scope course` — длины вариантов и абсолюты по
каждому языку; `check_edits.py` — не сломала ли правка то, что было целым (повтор с соседним
вариантом, сменившаяся мысль, одноязычная правка без пары). Все находки разобрать поимённо
в отчёте: «находок N, из них дефектов 0, остальные — …». `npm test` — 1521 тест в 43 сьютах.
