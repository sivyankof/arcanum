# Arcanum · стратегия тестирования

## Уровни

**1. Типы:** `npx tsc --noEmit` после каждого шага (уже в процессе). Ноль ошибок всегда.

**2. Юнит-тесты логики (jest-expo).** Тестируем ТОЛЬКО чистую логику, НЕ компоненты (UI проверяет
уровень 3). Обязательные модули и источник кейсов — logic-spec.md:
- `src/lib/moon.ts` — фазы на известные даты (сверить с лунным календарём: минимум новолуние,
  полнолуние, границы фаз ±1 день);
- аркан рождения — три тест-кейса из logic-spec §5 (15.03.1994→V, 29.12.1987→XII, 01.01.2000→IV)
  + краевые: 22→Дурак, однозначная сумма;
- карта дня — детерминизм (один сид+дата → один индекс), анти-повтор (не выпадает из окна 7 дней),
  распределение (на 1000 сидов нет индекса с частотой >3%);
- серия — вчера→+1, позавчера→сброс, заморозка: тратится при пропуске 1 дня, не тратится при 2+;
- XP/уровни — формула урока (0 ошибок→10, 3 ошибки→4, 5 ошибок→4 не меньше), пороги уровней;
- SM-2 (`src/lib/srs.ts`) — интервалы после ответов качества 5/3/0 (кейсы добавить в logic-spec на этапе 3).

Правило процесса: задача, добавляющая формулу/алгоритм → в том же коммите тест на неё.
Запуск: `npm test` (добавить script). Все тесты зелёные перед каждым push.

**3. UI-проверка** — docs/ui-verification.md (скриншоты против макета + прокликивание). Уже в процессе (6а/6б).

**4. Ручная проверка на устройстве** — Артём на iPhone (шаг 6в): хаптика, шрифты, жесты, «ощущение».

**5. Перед релизом (этап 6):** прогон release-checklist.md на матрице: iPhone (последний iOS),
Android средний (эмулятор Pixel), Android слабый (эмулятор с 2GB RAM); обе темы, оба языка,
свежая установка + обновление поверх старой версии (миграция store!).

## Что НЕ делаем в v1 (осознанно)

E2E-автотесты на устройстве (Maestro/Detox) — дорого в поддержке для соло-проекта; заменяет уровень 3.
Snapshot-тесты компонентов — ломки при каждой правке стилей, шума больше пользы.
