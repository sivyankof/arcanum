# Arcanum — приложение для изучения таро (Expo SDK 54)

Офлайн-приложение: карта дня, каталог 78 карт, курс, расклады, флеш-карты (SRS). Весь контент в бандле, сервера нет.

## Команды

- `npm start` — dev-сервер Expo (`npm run android` / `ios` / `web` — сразу на платформу).
- `npx tsc --noEmit` — проверка типов (strict). Линтера нет.

Правило: новая формула или алгоритм — тест в том же коммите (`docs/testing-strategy.md`). ⚠️ Node несёт полный ICU, а Hermes на телефоне — урезанный, поэтому всё, что считает сам движок (формы числительных, даты, форматы чисел), обычным тестом не проверяется: механизм сносится руками до загрузки модуля — образец `src/lib/__tests__/i18nPlurals.test.ts` (hf-02).
- Веб-проверка (пункт 6а/6б процесса): `npx expo start --web` поднимает приложение на
  http://localhost:8081. Playwright в проекте НЕ установлен и ставить его не нужно — он есть
  в кэше npx, скрипт запускается так:
  `NODE_PATH="C:/Users/Artem/AppData/Local/npm-cache/_npx/705bc6b22212b352/node_modules" node <скрипт>`
  (внутри `require('playwright')`, вьюпорт 390×844, headless). Состояние приложения на вебе —
  `localStorage` под ключом `arcanum-app` в формате zustand/persist (`{state, version}`):
  AsyncStorage на вебе это localStorage напрямую, поэтому сид ставится одним `evaluate`.
  ⚠️ Сид ставить НЕ через `addInitScript` (он срабатывает на каждой навигации и затирает

## Архитектура

**Роутинг** — expo-router v6, file-based: дерево `app/` и есть маршруты.

**Контент** — статические JSON в `content/` (`cards.json`, `spreads.json`, `course.json`), доступ ТОЛЬКО через `src/lib/content.ts` (типизированные экспорты `cards`, `spreads`, `course`, `cardById`, `cardOfDay`). Каждая карта: 12 контент-блоков (general, reversed, love, career, finances, health, day_card, symbolism + четыре `*_reversed` спеки 25; у старших ещё `birth_path`), каждый блок `{ru, en, status}`, где `status` — словарь ПО ЯЗЫКАМ (`{"ru": "reviewed", "en": "draft"}`, спека 28а) со статусным workflow `todo → draft → reviewed → final`; языка нет в словаре = `todo`. ⚠️ Текст берётся `inLang` (фолбэк на английский), а готовность спрашивается у языка, который РЕАЛЬНО показан: `statusIn`/`blockText` из `content.ts` — прямое чтение `block.status` в экранах запрещено, иначе испанец получит «Текст готовится» поверх готового английского. Отсутствие ключа языка и пустая строка значат разное: `"es": ""` — это «испанский есть и он пустой», конвейеру такие заглушки создавать запрещено (контракт-тест `cardsContent.test.ts`). Слов у карты два набора: `keywords` — 4 слова витрины (чипы под названием), `search` — 8–12 скрытых поисковых синонимов, которые нигде не отображаются (правила подбора — `docs/content-guide.md`). Расклады и модули курса имеют флаг `free` (freemium).

**Изображения карт** — Metro требует статических `require`, поэтому `src/lib/cardImages.ts` — автогенерируемая карта id → require. Руками не править, только `python scripts/gen_card_images.py`.

**Состояние** — zustand + persist в AsyncStorage (`src/store/useApp.ts`): тема, язык, streak, история карт дня, повторение флеш-карт (`srs`/`reviewDay`, спека 45). Ключ хранилища `arcanum-app`, схема на persist version 10 — менять осторожно, данные уже персистятся у пользователей.

**Тема** — дизайн-токены в `src/theme/theme.ts` (направление «Небесное золото», dark/light + spacing/radius/fonts) — единственный источник правды по цветам. Экраны берут тему через `useTheme()` (режим читается из zustand-стора). Отдельных Themed-компонентов нет.

**i18n** — react-i18next, ресурсы inline в `src/lib/i18n.ts`. Языков четыре: ru/en/es/pt, тип `Lang` объявлен ровно один раз — в `src/lib/lang.ts` (там же эндонимы, локали, `detectLang`, `Localized<T>` и доступ к многоязычному тексту `inLang(запись, язык)` с фолбэком на английский; контентные блоки читаются ТОЛЬКО через `inLang`, прямая индексация по языку из кода запрещена). Единственный способ узнать текущий язык в компоненте — хук `useLang()`; самодельный каст языка контракт-тест `src/lib/__tests__/langSources.test.ts` не пропускает. `AVAILABLE_LANGS` — языки, у которых есть UI-строки (в dev-сборке — все четыре); язык, которого там нет, не появляется ни в пикере, ни в определении языка устройства. Язык лежит в zustand; корневой layout синхронизирует i18n на layout-эффекте, чтобы первый кадр не мигал прежним языком. `src/lib/deviceLang.ts` — единственный файл, знающий про `expo-localization` (язык устройства читается один раз, при первой установке). Новую UI-строку добавлять сразу в оба языка `i18n.ts`.

**Луна** — `src/lib/moon.ts`: точные моменты новолуния и полнолуния по Meeus (гл. 49), без зависимостей, ~1–2 мин точности (`phaseInstant`/`moonEvents`/`lunationAround`), фаза и лунный день считаются от них (окно ±0.92 сут вокруг ТОЧНОГО момента, hf-01). Сетка месяца и события по ЛОКАЛЬНОМУ календарю — `src/lib/moonCalendar.ts`; экран — `app/moon.tsx` (под гардом онбординга, вход — нажимаемая строка луны `MoonRow` на «Сегодня»). ⚠️ Допуск сверки с эфемеридами в тестах — 2 мин, НЕ шире: при 10 сьют оставался зелёным на перепутанном знаке ΔT. Тесты сверены с полным списком US Naval Observatory за 2025–2027 (74 момента). Пуши новолуния/полнолуния — замена утреннего в день события (`pushPlan.ts`, вид `moon`, спека 47б).

**SRS** — `src/lib/srs.ts`, чистые функции SM-2 по локальным дням (оценки 0–3) для флеш-карт (спека 45); сессия и сводка — `src/lib/review.ts`. Экран тренажёра — `app/review.tsx` (под гардом онбординга, вход — карточка «Повторение» над первым модулем таба «Курс»); общие компоненты, выросшие из задачи 45б — `FlipCard` (3D-переворот), `ResultPanel` (панель итога), `MeaningPanel` (панель значения), `KeywordChips` (чипы ключевых слов).

**Прогресс изучения** — `src/lib/collection.ts` (чистые функции: секции колоды по группам, прогресс «N из 78», `filterProgress` под активным чипом справочника; спека 46/46б) + фильтр `'learned'` в `src/lib/cardSearch.ts`; показывается на табе «Карты» (панель + приглушение неизученных + чип «Изучено»). Отдельного экрана альбома нет (первая редакция 46 снята как дубль справочника). Общие компоненты из задачи 46 — `CardCell`/`CardGridRow` (ячейка и ряд сетки карт), `StarBack` (рубашка со звездой, расклады).

Alias путей: `@/*` → корень репозитория. Комментарии в коде — на русском.
